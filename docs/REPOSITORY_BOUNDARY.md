# 仓库与产品边界

GeoD Agent 在本仓库独立开发、版本管理、测试和发布。旧 GeoD 桌面端及其 CLI/MCP 留在 [`geo-downloader`](https://github.com/gaopengbin/geo-downloader)；GeoD Global 留在独立仓库。三个产品不共享安装目录、更新通道或本地任务数据库。

## 可复用的能力

- GeoD Agent 可以调用既有 GeoD 账号与身份接口，并为托管模型申请独立的产品权限。模型调用、配额与用量结算由服务端完成；图源下载与文件处理由用户设备完成。
- 旧 GeoD 下载代码是实现参考，不是本仓库的运行时路径依赖。迁移经过源码归属、许可与来源记录、兼容性测试和版本化发布；禁止使用 `../tif-downloader`、绝对本机路径、符号链接或 `file:` 包依赖作为发行方案。
- 任务合同、manifest 与图源策略通过明确版本的 schema 和适配测试对齐。旧桌面、CLI/MCP 仍按各自的仓库与发布节奏维护；Agent 首发只承诺已通过真实样本验收的影像链。

## 当前状态

本仓库已有独立的瓦片格网计算、本地计划内核、版本化合同、合成样本和[本地任务账本](implementation/2026-09-28-task-ledger.md)。没有桌面安装包、模型网关或下载任务实现。
