# GeoD Agent 使用统计

仅统计独立 GeoD Agent。账号源为 GeoD 自己的账号服务，不读旧桌面遥测或微信工具账号，不把共享注册账号都称为 Agent 活跃用户。

## 查询

`scripts/Get-GeoDAgentActivity.ps1 -Hours 48` 通过固定主机密钥 SSH 只读执行采集器。可指定带时区的 `-Until` 和本地 `-OutputFile`。默认排除已确认的两个主账号及服务端 internal 标签。其他未标记测试账号不能自动认定为外部用户。

- 注册：GeoD 共享账号注册，并不证明安装或使用 Agent。
- 桌面授权：只筛选 `clientId=geod-agent-desktop`；授权轮换可能来自后台刷新，不当作任务执行。
- 托管/赞助模型：来自服务端 `model_generations`，与自有渠道分开。
- 自有渠道：新客户端明确开启“Agent 使用统计”后，由原生 `save_generation` 记录 started/completed/failed/interrupted；未知 Token 保留 null。不进入收费账本，不扣 Credits。
- 活跃会话：统计开启后当前原生后台会话首次观测，按账号与本次后台进程去重，不等同一次前台点击或精确的系统启动次数。
- 下载：沿用独立“下载使用统计”与原生持久化队列，覆盖影像及通用数据下载。无上报可能是旧客户端、未同意统计、离线或未下载，不能直接当作没下载。

## 新增数据合同

`POST /api/agent/activity`，沿用 GeoD Agent bearer 验证、账号绑定和事件速率限制。严格 allowlist 只接受随机事件 ID、时间、活动类别、状态、安全错误类别及可用输入/输出 Token。批量最多 20 条，90 天服务端保留，时间不可来自过远过去/未来。重复事件幂等，客户端自报不等同供应商账单或服务端核验的模型实际扣费。

持久化在独立 `agent_activity_events`；不写 model_generations、usage_ledger 或 Credits。应用不上传提示词、回复、模型名称、渠道地址/ID、密钥、任务 ID、文件路径和坐标。

统计默认关闭，按账号保存；不将旧下载统计授权迁移为模型统计授权。关闭清除该账号待上传记录；已发出的 HTTP 请求可能完成。模型路径仅本机最佳努力写队列，网络上传在原生后台，不在 HTTP 上传时持有 SQLite 写锁。断网或旧网关返回失败时保留队列，新版网关与新版客户端同时上线后才能采集。退出账号后不上传该账号积压；重新登录对应账号方可发送。
