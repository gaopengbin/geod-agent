# GeoD Agent 规则与历史上下文按需加载

## 运行方式

保留 Codex 0.159.2 核心及其完整持久化线程，在供应商请求边界生成按任务加载的输入。没有给长任务新增轮数、时长、费用硬截断，也没有降低模型上下文或输出上限。

- 常驻：产品身份、用户意图与澄清原则、实际权限、当前任务工作流、用户原话、问题卡片的已确认答案、被接受方案的原文、未完成操作、近期任务回执以及原生最新状态。
- 任务相关规则自动加载：影像、图源、地图、数据库、定时、子任务、后台命令等规则分组；发现对应工具后同步加入相关规则。
- 其他详细规则和技能目录通过只读 `runtime_context_read` 检索。完整工具定义仍向 Core 注册，由实际人类意图选择初始工具组，其他工具支持按需发现。
- 旧的大段工具结果、参数、助手文字与上一轮推理保存在本地会话归档，模型收到资源引用和关键事实；完整原文可分页取回，重启后仍可恢复。权限、任务完成状态由原生服务判定，归档不是授权或完成证明。
- 当前长任务的推理链、未完成工具调用和最近 8 个已完成调用的回执保留。这里的 8 是近期原文窗口，不是任务执行次数上限；更早原文仍可取回。Core 内部压缩使用完整原始来源。
- 已确认坐标系保持原任务作用域，继续或修改缩放级别不重新询问，不将单任务选择提升为会话默认。现有后台等待与完成登记仍由原生服务处理。

相关实现：`model-input-context.mjs`、`codex-host.mjs`。输入审计只记录字节大小、分组、工具名称等元数据；实际 token 和费用来自供应商及账本回执。

## 真实故宫任务对比

保持原始 Core 历史分支及 18 条界面历史，使用同一个真实 `deepseek-flash` 和同一计价版本。沿用故宫原多边形、Esri Wayback 2026-09-24 / release 63116、Z16、GeoTIFF、EPSG:4326、无压缩、无金字塔与附属文件，独立输出目录。

相对上一轮输入减少 50.38%，实扣减少 8.13%；相对最初版本输入减少 76.40%，实扣减少 69.71%。本次单次请求输入为 12,915～16,391 tokens；上一轮为 23,421～26,431。输入请求中的工具从上一轮 59 个降至 30 个，初始自动分组只有 imagery，7 个旧记录按引用保留。本次模型没有请求额外问题、没有调用后台轮询工具或完成登记工具。

费用没有与输入同比下降，原因是本次缓存命中率下降，未缓存输入仅从 18,972 降至 18,334。按上一轮缓存比例计算，本次 token 对应 70.48011 Credits；此数字只用于分析，不是实际账单。上述实际费用逐条核对供应商回执、原生回执与账本 generationId，且本次余额差额一致。

结果：9 个瓦片、501×522 像素、1,573,318 bytes、EPSG:4326，缺失瓦片 0，原生完成登记和文件校验通过，最终总结正常返回。栅格 SHA-256 与原始和上一轮产物相同：

`8c509872d93d10c24ab672f56d04d06f7de9f686f5393d20d12735c6ac7e0e1c`

本次实测扣 105.44544 Credits，余额从 198.30256 变为 92.85712，没有新发放测试额度。

这是单次同任务历史比较，模型采样和供应商缓存会变化；瓦片缓存已预热，不是冷启动下载速度测试。最初版本下载完成后余额归零，未产生最终总结；后两轮均有总结。长任务保真由另外的真实 Core 与本地供应商回归验证，没有人为拉长付费影像任务。
