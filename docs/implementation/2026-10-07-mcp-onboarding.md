# MCP 接入选项与高德本机认证

## 修复内容

- `mcp_connect` 接受当前任务中用户实际提交的问答选项内的确切 URL。未选项、未提交草稿、助手文字和后续独立任务不会授权连接。
- 已保存的回答、明确的“继续/重试”、重新打开会话后的问答提交保留原任务关联。修复中文标点紧接 URL 时的提取错误。
- 旧的高德 `MCP_URL_NOT_USER_PROVIDED` 失败记录可恢复为本机 Key 配置卡；原工具详情和原回答不被改写。
- 高德官方地址为 `https://mcp.amap.com/mcp`。本机表单填写高德 **Web 服务 Key**，测试成功后再确认启用。取消或关闭表单可通过会话卡重新打开；Key 不进入问答记录或模型工具参数。
- HTTP 查询认证参数与公共 URL 分开，保存至当前账号的系统凭据库。只在原生 MCP 传输边界组装请求地址。公共连接器元数据只包含参数名，更新/删除遵循账号隔离。
- 高德官方服务预设单独标明来源，不声称来自 Registry。普通 Registry 搜索保留用户代理策略，主域名失败后使用官方生产域名；错误包含超时、HTTP 状态或网络原因。
- 技能与连接器页面的高德添加入口复用同一本机认证表单，并提供 Key 更新入口。工具说明同步避免要求用户重复粘贴选项里已提交的 URL。

## 核验

- 19 项前端逻辑测试通过，含原任务授权、拒绝未选 URL、问答历史恢复、Key 更新和握手失败。
- 2 项原生凭据测试通过，含旧数据兼容、URL 参数编码、非法参数拒绝、凭据与 URL 分离。
- 原生桌面实际调用：系统凭据保存/读取、MCP 握手、工具发现、启用后工具调用、Key 更新、清理测试连接器。服务为本机测试服务器；没有调用模型。
- 实际 Registry 查询成功，高德预设返回官方地址和文档。注册表搜索 `amap` 的返回项为 `app.flamap/flamap`，不能将其误认为高德官方服务。
- 深色、浅色、窄屏表单验证通过，含关闭后重新打开、失败后重试、密码遮挡和无浏览器存储泄漏。
- 已在实际桌面会话恢复旧失败步骤的配置卡，并打开本机 Key 表单。未填写真实高德 Key，因此尚未宣称高德服务已连接。
