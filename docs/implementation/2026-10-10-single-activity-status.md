# 合并思考状态提示

用户反馈每轮开始时顶部和底部都显示“正在思考下一步”。原因是执行记录标题与底部固定状态同时使用同一个实时状态文案。

- 执行记录标题固定为“思考与执行”，使用静态图标，保留操作数量和展开/收起行为。
- 思考记录使用静态思考图标并保留详情，避免再展示一个通用等待动画。真实工具调用的逐项进度仍保留。
- 仅输入框上方的固定状态行展示当前思考、等待回答、调用工具或生成回复状态。滚动长记录或折叠执行记录后仍可见，结束或停止后消失。

验证：前端类型检查和构建通过；现有实际对话组件的隔离界面回归通过浅色、深色、360px窄屏、长思考滚动、折叠、回答问题后继续、工具执行、生成回复、新轮次及结束/停止。新增检查确认执行记录标题不重复实时状态，底部实时提示只有一条。已查看深色折叠截图。

证据：`artifacts/chat-activity-single-20261010/ui-report.json` 及对应截图。回归没有调用模型或实际下载；修改通过开发服务器更新，未发布安装包。
