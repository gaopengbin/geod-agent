# 当前可试用版本

本机开发窗口现在即可测试。继续使用热更新，不需要再次安装；原会话、图源、四个数据库连接及模型默认选择保留，测试模式不限额。

## 可试用范围

- 图源配置、密钥图源、缩略图和本机下载。
- 影像、矢量、三维成果，任务列表及后台恢复。
- OpenLayers 二维地图、Cesium 三维场景及对应 Agent 工具。
- PostgreSQL/PostGIS、SQLite、MySQL/MariaDB、SQL Server、Oracle，以及已验收的证书/加密私钥输入。
- 图片、GIS 范围、PDF、现代/旧版 Office、文本、OCR、音频及常见文档打开密码。
- 中文/英文、会话搜索和管理、分支、多会话并行。
- 本机 AI 定时任务、后台命令、备份、插件和四种模型协议/自有渠道配置。

具体真实供应商、格式及授权边界以 [当前验收清单](2026-10-04-product-gaps.md) 为准。
