# 数据库加密客户端私钥与实际验收

日期：2026-10-04。使用开发模式，没有安装应用、发布服务或开启收费。随后开始整合新的本地发行候选；候选的隔离运行另行记录。

## 已完成

数据库的本机认证表单支持加密 PEM 客户端私钥。选择加密文件后显示密码输入，错误密码清空并重新聚焦；移除私钥、关闭表单或保存成功均清除临时密码。中文暗色与英文亮色界面已实际核对，并补齐 PostGIS TLS 选项的英文翻译。

解锁使用应用自带 Python 和固定 cryptography 50.0.2；请求与解锁结果通过本机管道传递，密码和私钥不进入命令行或环境变量。不保存打开密码；保存的客户端证书和规范化 PKCS8 私钥使用 Windows DPAPI，绑定 Windows 用户、GeoD 账号目录及连接编号。数据库工具只返回连接引用和数据，模型请求不能直接填写密码、客户端证书或私钥字段。

用户提供的工作区连接 JSON 可包含 `sslClientKeyPassword`，由原生连接工具读取。该文件本身仍由用户管理；连接工具不把其密码或私钥返回给 AI。缺少密码、密码错误或证书不匹配时返回结构化错误，前台可以等待本机认证；关窗任务记录为需要输入，不自动弹出表单或浏览器。

## 同时修复

1. 调度器此前只识别抛出的需要输入错误。数据库工具以正常返回值携带 `USER_INPUT_REQUIRED` 时，模型虽告知需要输入，任务却被标为成功。现在两种返回形式均保留需要输入状态；新一轮真实关窗模型已核对。
2. 升级备份此前只保留连接配置和 CA，遗漏系统加密的客户端身份文件。现在备份包含数据/SQL 连接的 `.client-tls`；两项原生存储检查通过，并实际从完整备份认证到 PostGIS。此文件仍绑定原 Windows 用户及连接位置，不是跨设备密钥迁移。

最初的模型连接名称匹配、界面标签选择、后台状态和备份遗漏失败均保留。连接验收改为实际编号及实例端口匹配，没有为验证标签再次请求收费模型。
