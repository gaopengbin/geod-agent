# 当前会话任务列表与计划操作

## 本地开发版

- 暗色主按钮使用蓝底白字，禁用态使用独立配色，不再将整个按钮半透明。
- 对话中的待处理计划与右侧详情使用同一计划卡片，支持开始和丢弃；操作过程中显示等待动画。
- 右侧显示当前会话的全部计划，含尚未创建作业的计划。待处理和已结束分开显示，点击任务切换地图范围、进度和成果详情。
- 多选后可批量开始、丢弃或取消。每次确认模式需要核对所选计划；完全访问模式通过已有原生工作区权限校验启动。
- 下载取消沿用原生 `jobs_cancel`，支持排队、下载、暂停阶段。界面显示“已请求取消”，以后台确认后的真实状态为准；处理、核验阶段没有提供尚未实现的取消操作。
- 丢弃是可恢复的计划状态，不删除本机文件或成果。状态独立保存于账号与会话对应的本机存储键中；历史里可以恢复。
- UI 与模型启动共用按计划串行的操作锁。模型读取或启动已丢弃计划时得到 `PLAN_DISCARDED`，旧工具执行结果不会重新将该计划加入待处理列表。
- 批量调用逐项读取本机状态，重复启动和已开始计划的丢弃均被拒绝。部分失败继续处理其他项，并分别展示成功数量与失败原因。
- 后台监控覆盖当前账号保存的所有会话的已知作业；不调用模型轮询进度。任务列表和操作仅针对当前会话。
- 任务行只高亮，不缩放；详情保持原有折叠和进度动效。
