## 原有环境恢复

`release-qa-profiles.py` 在应用退出后，将当前 Windows 用户的 Roaming/Local 两个 GeoD 应用目录移到同卷备份；结束时将测试目录移到同卷独立位置，再恢复原目录。原目录和备份路径受到明确的目录边界检查，不递归删除用户数据。

第一次恢复检查发现跨磁盘 `rename` 不可用，已改为同卷归档并完成恢复；数据库测试也已改为使用实际测试库目录中的图层。这些验收脚本修正没有改动安装包。

`development-restored.json` 验证恢复后的实际桌面版本为 0.2.0，账号连接正常，原有 30 个会话与当前选中会话可读取，原子任务及成果仍在，后台与最新开发程序指纹一致，输入框可用，页面异常为 0。对应截图：`development-restored.png`。

测试档案可能包含应用私有数据，保留在当前用户 AppData 的 `dev.geod-agent.desktop.qa-result-*` 同卷目录；位置记录在 `profiles.json`。这些数据没有放进安装包或便携 ZIP，不能作为公开发行文件。

## 本轮验收边界

- 这是同一 Windows 用户下的应用目录隔离，系统凭据库和现有 WebView2 仍可用；没有声称完成全新 Windows、首次安装或全新账号验收。
- 升级场景是旧开发程序的空闲后台切换到真实 release 程序，没有测试安装向导覆盖旧安装版或运行中任务的热升级。
- 本轮真实 AI 验证连接本机候选网关。新增接口的正式环境兼容验收与网关发布另行进行。
- 一次性指令的停机补执行与重启幂等已验证；长时间停机后的多周期合并和长期稳定性仍需后续验收。
- 干净 Windows 验收依用户指示暂缓。正式支付、线上发布均未启用。
