## 发现并修复

1. **正式计划生成前的参数延续。** 原逻辑只从已创建的原生计划继承投影，遗漏了缺凭据时已在问答中确认的参数。现在显式“换源、其他设置不变”的同任务修改可追溯并沿用实际用户 CRS 回答；不信任模型自己提出的 CRS，不继承旧审批，不替用户回答新的图源问题，独立任务仍单独澄清。
2. **停止等待与失败分离。** 本机审批等待抛出明确的 `USER_STOPPED`，界面使用中性停止记录。运行层仍保留未核实的原生副作用，不伪造成功或下载取消；通过任务 ID、计划哈希和新鲜原生回执核对，避免重复提交。
3. **回调关闭竞态。** 手动停止先结束 Core 回合、后结束本机回调时，原逻辑会生成 `OPERATION_RESULT_UNKNOWN` 并累加失败。现在把停止原因绑定到原回合，后续回合已经开始也不会丢失这个来源；非用户停止导致的原生状态不可用仍保留错误。
4. **规划的持久化身份。** 原生影像规划采用运行层分配的稳定操作 ID；模型换调用 ID、进程恢复后仍可打开原来的计划回执。只对经过审查、具有本机幂等回执且不启动下载的规划工具开放这条恢复路径；未知外部写操作继续要求核对。旧记录缺稳定 ID 时，只有完整、可读的原生账本证明没有计划才允许恢复。
5. **错误的投影选项。** 真实模型将 EPSG:4547 描述为中央经线 117°E，PROJ 数据实际对应 114°E；117°E 对应 4548。新增本地 EPSG/PROJ 参考，对问答中明确声称的中央经线进行一致性检查，返回可修正的错误给模型，冲突选项不展示给用户。重跑时再次出现同类错误，实际拦截后模型改为 4548，再展示问答。未替用户选择投影。

参考数据只用于本机一致性检查，不随初始提示词发送给模型；原生 GDAL 的有效投影校验继续保留。数据源版本、哈希、重建脚本和许可说明一并保存。
