# 轻量基础包与可选 GIS 技能

本轮按用户要求移除 Java、Tika、Apache POI 和本地 OCR。旧版 DOC/XLS/PPT 请另存为现代 Office 格式；有文字层的 PDF 继续本机读取，扫描页明确标记未识别，可使用视觉模型读取页面图片。已有历史附件正文与 OCR 元数据保留。

默认资源从八组改为六组：Codex、pgEdge、DBHub、文档解析、音频工具、纯 Python 解释器。基础安装不含 GIS 原生库；GeoJSON（WGS84）、手绘范围、行政边界、瓦片下载和拼接保留。普通文档和数据库 TLS 解析使用小解释器及文档依赖，不再依赖完整 GIS 环境。

## 独立技能

| 技能 | 工具 | 依赖 |
| --- | --- | --- |
| 多格式范围导入 | vector_info、内置 data_input_read | 公共＋矢量 |
| 矢量转换 | vector_info / convert / reproject | 公共＋矢量 |
| 矢量分析 | vector_info / clip / buffer / simplify | 公共＋矢量 |
| 栅格检查 | raster_info / stats | 公共＋栅格 |
| 栅格转换 | raster_info / convert / reproject | 公共＋栅格 |

依赖为已验收 wheel 的固定版本切片：公共 10,958,891 字节，矢量 39,419,736 字节，栅格 30,861,113 字节。多个功能共享相同的组件，不重复下载 NumPy。完整组件解压约 260.8 MB，减少 FastMCP、Fiona、测试和未使用的依赖。

每项技能有真实 SKILL.md、账号归属及专用 MCP 连接器。新 MCP 适配器使用标准库与已安装的引擎，只有该技能的工具可调用；停用技能同步停用连接器。原 GDAL 整体连接器提示迁移到独立技能。写入仍受原生工作区和完全访问权限检查约束，禁止越界与覆盖已有文件。当前几何简化仅公开 Douglas-Peucker，栅格统计公开逐块基本统计，不宣称未实现的分位数和直方图。

安装支持在线下载及离线组件目录，编译目录固定版本、下载大小、SHA-256 及清单摘要。下载校验后在应用自有临时目录解包，逐文件校验后原子启用；启动前复验文件。安装失败可重试，已安装依赖可共享。组件仅包含可执行依赖，不含账号凭据或模型密钥。
