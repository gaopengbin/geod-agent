# 本地插件、显式记忆与对话持久化

## 已完成的本地功能

技能与连接器页面增加「插件」「记忆」页签，延续现有页内布局。

- 插件支持根目录 `plugin.json` 的 Agent Plugins 格式，以及 `.codex-plugin/plugin.json` 兼容格式。当前组件是 Skill、stdio MCP、Streamable HTTP MCP；同名技能加插件命名前缀。
- 先读取整包快照，导入时核对 SHA-256，再复制到应用自己的目录。原文件夹移动后仍可运行；整包启用、停用与移除会同步处理组件。
- 私有 MCP 的实际参数、环境值和请求头保存在本机凭据库；预览只显示字段名称和参数数量。新导入的插件、技能及连接器按 GeoD 账号隔离。
- 用户可以明确要求 AI 记住、修改或忘记偏好，也可在页内编辑、停用、搜索与删除。账号范围跨工作区使用，工作区范围只用于实际绑定的目录。
- 偏好写入本机 SQLite，编辑和删除检查版本；每一轮读取当前启用的偏好。Codex 自动记忆合并关闭，避免形成看不到、无法管理的第二套自动记忆。
- 旧 Codex 线程可通过 `extensions_list` 发现 `builtin-agent-memory` 后调用相同工具；原会话保留。旧线程这一兼容路径尚未单独完成真实 AI 验收。

## 真实验收

`artifacts/plugins-memory-20261003-final/acceptance.json`：12 项实际桌面验收全部通过。真实托管模型使用导入的技能，调用安装后的私有 stdio 与 HTTP MCP，读到随机生成的实际文件编号。随后真实 AI 保存一条用户明确要求的偏好，新 Codex 会话读取该偏好，页内编辑停用，真实 AI 删除；本机记录与工具调用一致。验收结束清理临时插件和偏好，不保留测试凭据。

原生库测试：记忆隔离、版本冲突及 SQLite 重开 1 项；插件快照、命名空间、账号导出、路径和变更拒绝 2 项；原有技能导出 1 项。TypeScript 检查通过。界面截图位于同一验收目录。

## 这轮实际发现并修复的存储问题

第一次真实 AI 调用已正常返回，但页面留下「待恢复请求」。当前页面 `localStorage` 共占 5,152,831 字符，对话和地图记录接近浏览器容量上限；新的请求恢复记录写入失败，完成时请求编号因而不一致。没有修改模型回答或伪造成功状态。

对话、恢复记录、地图命令、工作区列表、计划名称、任务丢弃记录和手绘范围书签改存 IndexedDB。小型主题等设置继续使用原存储。迁移先完整提交，再移除旧记录；已有新存储记录优先，不被旧副本覆盖。模型工具执行等待恢复记录提交，完成回答先提交完整结果，再清理待恢复状态；写入失败会明确显示并阻止后续工具执行。

`artifacts/local-state-20261003/acceptance.json`：实际页面迁移保留 30 条会话及 40 份地图记录；保存 6,291,511 字符记录并真实重载读取成功；原待恢复请求通过实际网关状态核对后释放，没有重跑插件工具。3 项存储测试加原有恢复测试共 12 项通过，覆盖迁移失败保留旧记录、事务中更新、写入失败重试及重开。第一次失败前的本机状态备份保留在 `artifacts/plugins-memory-20261003-real/pre-migration-ui-state.json`。

## 范围与剩余工作

- 当前是本地插件管理，不是在线商店；不接管上游尚在开发中的插件安装 RPC。参考官方 [Agent Plugins 结构](https://developers.openai.com/plugins/build/plugins) 和 [App Server](https://developers.openai.com/codex/app-server/)。
- Hooks、App 映射、SSE、依赖自动安装和在线市场未接入；声明了不支持的组件会直接提示。
- 记忆删除不删除已有聊天记录；不会从工具输出中自动提取用户偏好。
- 子 Agent 事件、模型请求和工作区隔离仍待完成，未直接启用上游多 Agent 开关。
- 开发模式热更新，本轮没有重新安装或发布服务。
