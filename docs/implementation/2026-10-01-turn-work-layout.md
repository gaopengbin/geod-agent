# 整轮思考与执行区

## 本次修复

- 按 turnId 将思考摘要、进度说明和工具执行合为一个可展开区块。旧会话按用户消息和最终回复分组，不改写保存的消息。
- 执行中默认展开；完成或停止时整轮自动收起。结束后仍可手动重新展开。
- 最终回复独立显示；已标记为 final_answer 的流式消息保持最终回复阶段。
- 展开区采用紧凑时间线。思考正文用 Markdown 排版；命令与输出、工具输入与结果分开查看。
- 用户确认卡、补充指令和仍在运行的后台任务保持可操作。
- 手动展开详情时暂停自动跟随，保持阅读位置。保留折叠过渡、状态动画和流式光标。
- 最小字号 14px；无原生 title 提示。
