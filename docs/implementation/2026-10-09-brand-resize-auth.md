# GeoD Agent 图标、面板拖动与授权状态修复

## 图标资产

- 使用 `assets/branding/geod-agent-v2-violet` 的紫罗兰 G 与四角星，替换 `public/geod-symbol.png` 和本地品牌源图。
- 横版标识和桌面图标保存到 public；Windows ICO、macOS ICNS 和 Tauri 多尺寸 PNG 同步更新。新构建的窗口与托盘复用该应用图标。
- 既有界面操作颜色保持现有样式，品牌图标采用新资产。

## 面板拖动

- `workbench.tsx` 在 pointer move 时仅缓存最后一次位置；每个动画帧更新工作区 CSS 网格和分隔条位置，结束拖动后提交 React 状态并保存宽度。
- 移除了每次 pointer move 的 `setPreferred`，以及会被重渲染覆盖的拖动中偏好引用赋值。
- `resizePanelWidths` 优先压缩紧邻面板，到达最小宽度后继续由其余邻近面板提供空间；所有面板宽度之和不变。
- 1120px 以上的任务视图使用真正的四列布局，任务面板参与分配宽度；移除原本覆盖在地图上的浮动 inspector 分隔条。
- 地图的尺寸更新合并到动画帧；已完成的 Markdown 块通过 memo 避免流式回复或布局变化时重复解析。

## 登录提示

- 凭据库按身份服务共享，旧刷新锁却位于各自应用配置目录。开发版、安装版或其他配置目录可能对同一份轮换凭据并发刷新。
- 增加与凭据库键一致的用户级共享文件锁，用于刷新、OAuth 回调写入、读取状态以及退出登录；保留原配置锁用于同配置旧版本兼容。
- 刷新失败后先比较凭据库的新值，避免旧请求删除已替换的有效登录凭据。
- `current_user_id` 直接返回本次认证快照的用户，避免刷新后再次无锁读取带来的竞态。
- 原生 API 返回 AUTH_REQUIRED / AUTH_EXPIRED 时立即重新核对账号状态；已连接账号定期及窗口聚焦时核对，避免长期显示缓存的“已登录”。不自动重放写入或下载操作。
- 状态重新确认为有效连接后，清除右侧残留的确切登录提示；普通权限或网络错误仍正常显示。

截图中的具体错误没有对应请求日志，无法单凭截图证明它由凭据竞态触发；本轮修复了代码中可重现的竞态和状态同步缺口。
