# 对话内按需安装 GIS 技能

影像规划、在线矢量导出先核对实际依赖；高级范围文件读取遇到明确的 GIS 缺失错误时，挂起原调用并显示安装卡。

- 影像重投影只需要 `gis-raster-convert`；矢量导出使用 `gis-vector-convert`；多格式范围读取使用 `gis-import`。
- 安装卡由本机缺失检测生成，不能由模型文字代替用户批准。按钮确认后下载 GeoD 固定版本组件；核验包大小、SHA-256、清单及展开文件哈希，登记账号所属技能和连接器。
- 下载、核验、安装各有独立状态。仅下载有真实百分比，核验和安装显示活动进度条。
- 下载大小排除已安装组件和已核验压缩包缓存。共享依赖避免重复下载。
- 原工具调用等待安装完成后执行，范围、图源、导出坐标系和格式保持原值；不生成虚构的用户消息。用户改变请求时重新规划。
- 取消会停止原调用，通知本机安装请求；在下一次下载读取或阶段检查时停止安装。已核验缓存保留。失败可原卡重试。
- 安装卡属于发起会话；切换可见会话不会丢失正在进行的安装。安装不替代影像下载计划确认。
