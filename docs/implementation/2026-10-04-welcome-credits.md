# 新用户体验额度

## 规则与接入

- 同一 GeoD 账号首次启用 Agent 钱包，自动领取 **20,000 Credits**，等于 20 元 GeoD AI 计费余额。已有 GeoD 账号首次启用 Agent 钱包同样可体验；已领取或已有充值批次的钱包不会再次领取。
- 仅在网关验证 GeoD OAuth 账号、客户端、权限范围和有效期后发放。客户端没有领取接口，不能传入收款账号或赠送数量。
- 赠送记录和余额批次在同一个 SQLite 事务中保存，`(account, kind)` 唯一。重复登录、换设备、并发、服务重启及新赠送政策版本均不重复领取。
- 赠送余额直接用于托管模型，按供应商返回的输入、缓存和输出用量结算；请求先预留，无法确认的请求保留预留。自带 Key/赞助渠道不扣此余额。
- 赠送与现金订单分开记录，优先消费赠送余额；赠送没有现金退款订单。无需开启充值或配置支付宝商户即可使用。
- 默认普通 `enforced` 网关自动采用上述规则；明确的 `unlimited` 开发网关仍保持无限测试，不发放或扣减赠送额度。已有支付配置需显式设置赠送数量。
- `GEOD_AGENT_WELCOME_CREDITS=0` 停止新赠送；已创建的体验钱包继续读取和结算。原钱包数据库必须持久化，不能通过重建数据库保留一次性领取记录。
- 界面只显示服务端实际返回的赠送记录；网络失败不会在本地伪造余额。中英文、深浅外观和窄窗口已验证。
