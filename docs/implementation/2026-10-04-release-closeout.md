## 正式地址发布门禁

实际默认正式地址模型请求失败。只读核对确认，线上服务 `geod-agent-source-config-20260930` 的代码缺少 `/api/agent/codex/generations/stream`；本地新版的真实模型流程通过。

另一个独立问题是旧 Nginx 对可选支付状态返回 HTML 404，导致客户端报响应无效；RC2 已修复并通过实际线上代理响应验证。只有可选支付状态 404 能降级，其他错误仍按真实类型返回。

配套网关已形成完整可审阅候选，见 [0.2.0 网关发布候选](2026-10-04-gateway-020-candidate.md)。**本地发行候选已验收；默认托管模型公开发行仍等待网关授权发布和真实线上模型复验。**

全新 Windows 与真实系统重启按用户指示暂缓。正式服务发布、签名更新渠道和真实收费需要对完整候选审阅后授权。
