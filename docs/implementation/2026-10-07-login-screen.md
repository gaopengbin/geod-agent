# 独立登录页

用户选择：独立登录页，继续使用已有的浏览器 GeoD 账号授权。

## 实现

- `src/login-screen.tsx` / `.css`：独立的品牌与账号入口，沿用当前 LibreChat 风格、中性色、共享按钮、Inter 与中文字体。未登录时隐藏工作区及标题栏的工作区操作。
- `src/geod-login.tsx`：登录、读取保存授权、打开浏览器、等待回调、失败和重新检查状态。登录页仍可打开网络与代理、语言和外观设置。
- `src/geod-auth.ts`：一个共享的账号状态控制器，沿用 `auth_status`、`auth_begin`、`auth_logout`。不改认证服务、口令或令牌保存方式。避免重复授权与重复轮询，在连接成功后停止授权轮询。
- `src/app.tsx`：按真实账号状态显示登录页或工作区；工作区保持挂载。`AgentPanel` 使用同一控制器，原聊天内登录入口删除。既有账号范围隔离逻辑保留。
- 中英文文案及减少动态效果支持。

## 验证

- `npx tsc -b`：通过。
- `npm run build`：通过；原有大型地图代码块警告仍在。
- `node test/login-screen-ui.mjs`：通过。运行真实 App 与控制器，使用隔离 native IPC 合同数据，无真实 OAuth、账号、模型、支付、消息或下载请求。
  - 初次检查只调用一次账号状态查询。
  - 未登录时不暴露聊天、导航、地图选范围。
  - 网络、语言、主题入口可用。
  - 键盘登录、多次点击只启动一次授权。
  - 等待授权、模拟成功后自动进入实际 App 工作区，停止授权轮询。
  - 退出返回登录；浏览器打开失败、拒绝授权、网络错误可见且可重试。
  - 已保存授权无需重复启动浏览器登录。
  - 初始登录状态读取失败与服务未配置分别提示，可重新检查恢复。
  - 未配置状态、英文、360px 窄窗口、减少动态效果通过。
- 真实运行的桌面 WebView 已观察到新登录页，工作区隐藏。仅截图和状态读取，没有操作真实登录按钮。

证据：`artifacts/login-screen-20261007/ui-acceptance.json`、`native-dark.png` 及隔离浅色、深色、等待、错误、英文窄屏截图。

本轮为前端热更新，未重装、重启桌面应用或发布安装包。真实账号授权端到端流程需要用户自行登录后验证。
