# GeoD Agent 启动动画

用户确认：每次启动应用播放一次，约 2 秒，然后进入登录页或已登录工作区。

## 实现

- `src/startup-splash.tsx` / `.css`：深蓝色品牌开屏、线框地球、轨道、扫描光和 GeoD 标志。复用现有标志与本地 Inter / Noto Sans SC 字体，不新增依赖、视频资源或网络请求。
- 根据已有界面语言偏好及系统语言自动选择中文或英文；分别显示“欢迎使用 GeoD Agent”与“Welcome to GeoD Agent”。
- `App` 挂载时开始 2 秒计时，计时清理适配 React StrictMode。账号状态查询并行进行，开屏不发起浏览器授权，也不等待网络查询成功。
- 底层登录页或工作区在开屏期间使用 `inert`，不接受键盘与鼠标操作；标题栏的窗口控制仍可用。结束时淡出，不因切换语言、导航或退出登录再次播放。
- 遵循系统减少动态效果偏好：保留欢迎页面与 2 秒时长，关闭动画。
- 扫描光仅为装饰，不冒充任务百分比或真实加载进度。

## 本地验证

- 桌面前端类型检查与构建通过（保留已有地图大包警告）。
- 真实 App 配合已有隔离 IPC 测试数据，7 个场景通过：中英文 1440×900、中英文 390×760、960×440、已登录账号、减少动态效果。
- 检查语言分离、无横向溢出和文本裁切、2 秒后解除 inert、账号状态仅查询一次、不启动真实授权、语言切换与退出登录不重播、无页面异常。
- 已观察并修复窄屏标题栏与开屏之间的空隙；桌面、窄屏及矮窗口截图已人工查看。

证据：`artifacts/startup-splash-20261009/acceptance.json`、各场景截图及中英文动画预览。
