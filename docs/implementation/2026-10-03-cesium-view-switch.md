# GeoD 工作区二维与三维切换

日期：2026-10-03。范围：本机开发版，热更新；没有重新安装或发布服务。

## 修复内容

截图中的三维连接器已能操作 Cesium 场景，但尚未提供 GeoD 工作区切换接口，因此模型无法执行“切换到二维”。本次补上实际工作区操作，而不是把相机俯视角或 Cesium 场景投影当作二维地图。

- 内置 Cesium MCP 新增 `getViewMode`、`setViewMode`、`closeScene`。工具总定义数从 64 增至 67；无三维场景时也可发现工作区工具。
- `setViewMode` 在 OpenLayers 二维地图和现有 Cesium 三维预览之间切换。隐藏三维保留 Viewer、相机、模型和图层，并暂停渲染；返回三维恢复同一实例。
- `closeScene` 单独释放三维预览，返回二维，不删除成果或取消下载。没有保留场景时切换三维返回 `NO_3D_SCENE`。
- 三维右上角新增“二维”按钮；二维右上角提供“三维”恢复入口。原关闭按钮仍负责释放场景。
- `getSceneState` 返回实际 `viewMode`、`visible` 和 `rendering`，区别隐藏场景与已关闭场景。
- 工作区操作绑定当前会话，提交 React 状态后才返回成功。处理快速连续切换、迟到结果和会话卸载，不能操作其他会话。
- Codex 与现有 Agent 引擎均获得工具发现说明，回答和操作由真实模型生成，没有替换模型回答。

## 实际验收

脚本：`apps/geod-agent-desktop/test/cesium-view-switch.mjs`。

使用当前会话已完成的名古屋建筑任务，没有创建新下载。通过生产加载接口、生产 MCP 调用与实际桌面窗口验证：

1. 三维切二维后，二维地图可见、三维隐藏且停止渲染。
2. 返回三维恢复同一相机和图层，重新开始渲染。
3. 两个界面切换按钮、连续切换、关闭后重开均可用。
4. 其他会话不能关闭当前场景。
5. 桌面页面错误为 0。

随后通过生产聊天输入框发送“切换到二维”“切回三维”。真实托管模型调用 `setViewMode` 并读取状态，两轮均完成，实际窗口模式正确，相机和图层保持不变。验收时间：2026-10-03 13:31:03（北京时间）。

## 验证边界

67 个工具定义不代表全部工具逐项验收。本次验证的是当前会话已有成果的二维/三维切换、场景保留和关闭生命周期。切换不会新建三维成果，也不会把 OSM 建筑体块变成实景倾斜摄影。
