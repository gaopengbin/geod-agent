# 输出预算、明确终态与逐项确认恢复

范围：GeoD Agent 开发版；未部署生产网关、未修改真实用户账本。实现保留 Codex 核心，不新增模型调用次数上限，也不自动重试 incomplete 或 402。

## 修复

- Responses 未指定输出预算时默认 16,384 token，且不超过上下文的一半；明确配置的上限仍保留。推理 token 也占此预算。生产赞助渠道原先显式配置 4,096，后续部署时必须同步审阅该配置，不能仅凭更新默认值声称线上已改善。
- 明确 `response.incomplete` / `response.failed` 与连接中断分开。保存上游原回执、响应 ID、模型、原因、输入/输出/缓存/推理用量。部分文本保留供诊断，不执行不完整的工具参数。
- 网关与自有渠道都保留 incomplete 回执；宿主将其作为本次请求终态交给 Codex，避免 SDK 把它当成可透明重试的网络错误。用户可从持久化步骤继续。
- 已知消耗使用独立 observed 记录，不计为成功回答，也不重复记账；客户 Credits 预留释放，赞助供应商未知消耗仍保留为未知。缺失用量不补零。有原始证据后可以 observe 核对，不将未完成请求改为成功。
- 会话用量面板、恢复检查及自有渠道累计支持 incomplete。已知 token 保留，未报告用量显示未知，不再永远显示请求仍在进行。
- 权限失败按原生任务资源隔离。状态指纹包含该矢量任务的原生状态和计划 hash；批准一个任务不批准另一个任务，也不要求把整个工作区改成完全访问。
- 执行策略使用完整的本机任务状态；发给模型的上下文仍只保留 32 条简短任务详情。因此较老的任务被上下文省略时，批准状态仍可生效，不以扩张模型上下文或限制长任务来解决。
- 查看 pending 提案不会误入原生下载等待。后台进程内部等待不再同步请求自身的后台 HTTP 入口。
- 后台审计过滤 content/reasoning 流片段，保留工具、完成项、终态与用量；删除因累计 2,000 条审计事件而终止有效任务的限制。
- OSM `highway=*` 解释为键存在。查询每个岛的保守外包框，再由原生几何过滤保留精确多边形相交要素并排除洞。较短的只读 Overpass 查询使用 GET，长查询仍使用 POST；真实诊断中同一镜像 GET 200、POST 504。不会通过重复模型调用处理此差异。

- 运行层：28 项通过，含 bundled Codex 的真实协议、工具契约与持久化步骤恢复测试。
- 原生等待与宿主：13 项通过，包含 pending 提案不等待下载、后台等待不消耗模型请求、中断不重复提交、完整结算前不执行工具。
- 会话恢复及用量展示：18 项通过。
- 原生渠道 4 项、审计事件 1 项通过；矢量引擎 11 项通过，包含实际 GeoJSON/GPKG 的洞、岛、交叉线与 HTTP 读取兼容验证。
- 原生任务状态 6 项通过，包含超过 32 项任务时执行策略仍能读取全部批准状态、模型上下文保持简短。
- Windows debug 构建、前端构建及最终 TypeScript 检查通过。具体运行证据保存在忽略目录 `artifacts/analytics/20261024-current`。

赞助 Luna 第一轮真实调用成功，第二轮返回 402，请求 ID `202610240954363023002868268d9d6of0WOw6T`。普通 Key 查询仍有额度；该响应没有足够证据确定是账号、分组、路由还是底层供应商余额。没有自动重试，没有关闭线上不限量。后续交付验收在本地测试网关手动切到现有 DeepSeek 托管渠道，不能称为 Luna 全流程验收成功。

站前区原任务 `8c5baa4f-5887-4fcd-a6f8-25740adbdce0` 实际下载 404 个要素，156,303 字节；后续恢复复用其原文件和原计划 hash。仅批准它时，西市区仍为 pending。西市区原镜像出现 HTTP 504，恢复只处理该失败区域；来源改变会产生新的、需单独确认的计划。

最终交付：站前区 404 要素 / 156,303 字节，西市区 623 要素 / 273,964 字节，两个 GeoJSON 均为 EPSG:4326，实际文件解析与原生 inspect 通过。西市区最终使用已实测可读的 overpass-api.de GET 接口。两份文件本次返回的都是道路；消防设施筛选已包含，但此 OSM 快照没有返回匹配要素，不能据此声称现实中没有消防设施。

最终交付清单见本次验收目录中的 `acceptance.json`，包含完整文件 hash、计划 hash、完成时间和复用证明。站前区文件 hash、计划 hash 与完成时间未变；西市区获准的最后一个计划 hash 在执行后也没有变化。保留原失败、取消及未启动镜像计划，不把它们当成功或删除历史。

最终真实模型复核运行 `0b209cbf-0e2e-44e3-adb7-6a082712df64` 返回 succeeded/completed，读取既有文件并给出交付清单，没有新建下载。此前在交付已完成后的额外网络探测阶段出现过一次 GATEWAY_ERROR，对应生成 ID 没有出现在本地测试网关账本；错误原文不足以确认具体拒绝原因，没有将其用量补零。保留了该失败运行，单独复核已有成果后完成交付。测试后恢复开发配置中的原网络设置，不修改系统代理或生产配置。
