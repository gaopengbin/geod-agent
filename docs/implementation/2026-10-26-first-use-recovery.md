# 首次任务准备与恢复验证（2026-10-26）

开发版修复及本机实测已完成；本次没有部署网关或发布安装包。继续使用 Codex 核心，没有新增模型调用次数上限。

## 修复的问题

- 新会话的引擎选择不再取决于异步可用性检查的首帧结果，避免首次渲染把空会话固化成兼容引擎。既有会话选择保留。
- 图源缺凭据与凭据库不可读分开报告。源配置保存与认证就绪分开表示，规划前检查底图和注记认证；缺凭据不创建无效计划。恢复入口只编辑已保存图源的本机认证，不重复登记。
- 保存认证会自动续接原会话；续接记录保留原用户请求 ID，已确认参数及实际问答可在持久化后沿用，独立新任务不继承这些回答。
- 首次空图源列表同时提供真实预设技术参数，按需读取一次即可配置；不依赖模型猜服务地址或反复探索可选扩展。科学影像仍需核对相应连接和覆盖。
- 参数列表已明确 EPSG 时，后文“导出参数已确认”不再遮蔽该代码。源坐标系、含糊投影和多选代码仍需澄清。
- Windows 后台启动先请求独立生命周期；受限 Job 拒绝 breakaway（错误 5/87）时使用受管启动，并明确要求保持窗口打开。保留实际系统错误和早退诊断；恢复入口可在后台未就绪时操作。
- 运行层按具体图源认证修订及后台实际状态判断恢复条件。更改下载级别、计划编号或无关连接不能绕过同一未解决前置条件；独立图源不受牵连。未知副作用仍需核对，不能自动重发。
- 自有渠道非成功响应经受控读取、脱敏和分类后留存请求 ID/拒绝类别；不保存上游错误正文。赞助用量目录兼容新增的 unknownUsageRequests 字段。
- 同步共享工具说明与实际任务级审批能力，避免模型收到“每次确认必须改完全访问”的过期说明。
