# 3D Tiles 多边形范围过滤

`geod-tiles3d::DownloadRequest.boundary` 接收与影像、矢量范围一致的 `BoundaryGeometry`。下载前归一化坐标，并验证每个多边形的外环、洞与拓扑；生成清单保存同一边界，离线检查重新验证。

选择规则：

- 显式 tile 和单独 content 的 `boundingVolume` 都参与范围过滤。
- `region` 使用全球经纬度矩形，跨日界线拆为两个矩形；不错误应用 tile transform。
- `box` / `sphere` 使用累积 transform 与既有保守地理包络。未知地理位置保留，以免误删。
- 与真正多边形相交，支持凹口、洞和不相连区域，不只比较总外包矩形。
- implicit 四叉树 / 八叉树在请求 subtree 前使用相同过滤器，之后按可用性展开并再次检查内容。
- 下载的是相交的完整模型瓦片，不切割模型网格。保守包络可能保留边缘额外瓦片。
- 粗外包络相交、嵌套外部 tileset 紧包络不相交时，该分支保留为有效空结构；不会导致其他有效分支下载失败。若最终只有空结构，没有真实模型或点云，拒绝发布“完成”成果。

## 验证

`cargo test --offline --manifest-path crates/geod-tiles3d/Cargo.toml`：15 项通过。

- 本地真实 HTTP 服务覆盖凹口、洞、离散区之间的空白：被排除 tile / content 0 次请求，未知位置分支保留。
- implicit 3 层四叉树中两个离散小岛：21 个可用节点只请求 5 个相关 subtree 和 5 个模型，两个目标叶子都保留。
- 变换后的 box / sphere 位于洞内时排除，穿过洞边缘时保留；地心未知位置不误删。
- 跨日界线 region 与分割后的 AOI 两侧均匹配，中间区域不误匹配。
- 嵌套空结构与正常分支可以共存；全为空结构则不生成完成目录。

此轮核心验收使用可记录每次请求的本地服务，不能替代用户私有图源或 Ion 账号的真实下载验收。
