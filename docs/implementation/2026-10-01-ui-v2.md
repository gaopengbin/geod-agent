# GeoD Agent UI v2 实施与验收

日期：2026-10-01

依据：[Agent UI 调研与方案](../design/2026-10-01-agent-ui-research.md)。本轮改动位于现有桌面前端，沿用 React、Motion、既有组件和 GeoD 蓝色主题，通过开发模式热更新提供。

## 已实施

- 工作台布局统一为导航、对话、地图、任务四个区域。宽屏支持拖动分隔条和键盘调整；中等宽度将任务作为地图上的侧栏，支持单独调整宽度；更窄窗口使用图标导航和视图切换。保存的宽度会适应窗口尺寸，并遵守可用区域的最小宽度。
- 任务与成果区将队列和详情分开滚动，列表保持有界高度。详情提供任务详情、成果、输入范围三个标签；路径、参数等较长内容放入折叠区。保留多选、批量操作、确认、丢弃、取消和恢复。
- 多个任务在聊天中使用紧凑汇总入口，点击后定位任务区；思考与执行仍按整轮收起。显示层合并重复消息 ID 的流式重放记录，使用最新内容，避免重复展示。
- 图源和技能与连接器页面提供列表与详情区域；窄窗口将详情作为页内视图，关闭后返回列表。继续使用原来的实际连接、测试、启用和编辑操作。
- 统一主题变量、间距、标题栏和面板栏密度。保留思考、工具、流式输出和滚动动效，列表悬浮只改变状态。暗色按钮使用清晰的前景色，地图保持现有简洁布局。

## 验证

| 项目 | 结果 |
| --- | --- |
| TypeScript 与 Vite 构建 | 通过；仍有原有的大体积 bundle 提示 |
| 布局、任务队列、整轮记录、任务摘要测试 | 26 项全部通过 |
| 布局宽度 | 检查 390、800、960、1280、1440、1920 px；未出现横向溢出 |
| 任务数量 | 实际组件展示 1、8、32 个演示任务；32 项时列表独立滚动，聊天汇总入口约 60 px |
| 分隔条 | 检查拖动、方向键调整、宽度保存及窗口尺寸变化；中等宽度任务侧栏独立调整 |
| 页面与焦点 | 检查任务标签键盘切换、导航展开与关闭、图源详情及编辑、连接器宽窄布局和详情返回 |
| 主题与字体 | 检查浅色、暗色、中文字体；浅色主题启用按钮白字与蓝底对比度约 4.97:1 |
| 浏览器日志 | 最后验收无 error；隐藏地图时仍可能出现 OpenLayers 零尺寸警告 |
| 开发运行 | Vite 1420、本地网关 43123 与桌面开发进程在运行；使用热更新 |

运行命令：

```powershell
rtk proxy npm run build
rtk proxy node --test test/workspace-layout.test.mjs test/task-queue.test.mjs test/chat-work.test.mjs test/task-summary.test.mjs
```

以上命令工作目录为 `G:\code\geod-agent\apps\geod-agent-desktop`。

## 验证范围

本轮验证前端组件、布局与交互，未重新执行付费模型、PostGIS 查询和完整影像下载链路。输入范围标签显示计划的范围与裁剪信息，不是新的数据库表浏览器。消息重放合并只作用于显示层，未修改已持久化的消息内容。开发版沿用原有后端操作和权限检查；本轮未重新安装或发布。
