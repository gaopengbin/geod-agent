# 默认诊断与客户故障复核（2026-10-29）

## 已实施的功能修复与未确定事项

- Agent 的分盘预算重复计算和 Windows 长共享缓存路径提交失败，已在 0.2.15 发布；本轮真实运行又覆盖了缓存 C 盘、成果 G 盘的实际卷查询与 GeoTIFF 交付。不是客户外接 E 盘的同机复现。
- 本机 12 组高德 HTTP/HTTPS、卫星/两类常见注记、带/不带原请求头的对照均返回 200。客户手动注记模板与原网络条件缺失，历史 403 根因仍未知。
- 旧版下载器曾对无关图源添加 Google Referer，本轮改为匹配真实服务域名的默认头，显式图源请求头仍优先。
- 旧版原先先取全部底图再取注记，本轮在批量前使用真实下载通道逐层核验。明确拒绝提前失败，错误指出底图/注记；成功样本写入正常任务目录，后续及恢复会直接复用。采样无覆盖不推断整片无覆盖，不更换已确认图源或请求参数。

## 默认开启的修正

- Agent 下载诊断在首个所属任务前、状态读取和后台采集时初始化，告知确认与开关分离；没有界面点击也能记录结果。
- 修复旧下载统计和使用统计把缺失浏览器设置当作 false、自动写回后台的问题；由 native 保存账号偏好，迁移旧浏览器中的明确选择。未知显示读取中，不误显示关闭。
- 默认开启基础诊断和使用统计，清楚说明账号关联及字段，提供关闭入口。保留可识别的明确关闭选择；旧版自动保存的默认关闭不再当作用户选择。旧版没有记录来源的状态会按新版默认迁移并在告知中显示当前开关。
- 旧版默认 enabled，保存偏好完成读取后才允许发送，单独保存告知已读版本，关闭/知道了不会再充当开启门槛。开发/验证构建仍受原 internal-run 隔离策略保护。
- 不上传对话、坐标、文件名、完整路径或密钥。官网中英文说明及应用内范围保持一致；首次观测不计作首次安装。

## 已执行验证

- Native 单元覆盖默认采集、未点告知仍入队、主动关闭保留、旧隐式 false 迁移、账号隔离及事件去重；原有任务/审批回归保留。
- Agent 测试账号真实运行：默认无点击下载成功、明确关闭时下载成功但不上传、重新开启后成功、受控注记 403。线上核对 3 个终态、关闭任务缺席，以及默认启动/首次观测/上报状态共 3 条基础事件，内部账号排除通过。实际使用不同的 C/G 卷，不以模拟空间冒充实测。
- 旧版先验检查测试验证注记拒绝前只发出逐层样本请求，恢复后底图和注记各样本不重复下载。真实高德下载与受控 403 通过正常生命周期生产器上报；测试安装 ID 持续排除。
- 界面验证覆盖默认开启、告知确认不改开关、关闭跨刷新保留、账号迁移，以及中文/英文窄屏暗色布局。隔离界面预览没有发送生产统计。
- 当前开发版版本 0.2.16，独立启动并保留会话与任务；测试不调用真实模型，不更改上游路线、额度或账本。

## 限制

没有取得客户原始手动注记 URL，没有复现其移动 E 盘、文件系统和网络环境，也没有重跑 40,200 张整任务。不能把根因未知写成已根治。用户主动关闭或设备离线时，远程结果仍可能缺失；已产生的本地诊断与待发送记录保留。

证据保存在 artifacts/default-diagnostics-20261029。正式版本以发布流水线的公开清单和消息回读为准，不以源码修改或本地测试替代发布。
