# 无法完成与未核实结果的明确收尾

本次变更在 GeoD Agent 开发版验证，未发布安装包，未修改生产网关、额度或账本。继续使用 Codex Core，不增加模型调用次数上限，也不以任务运行时间判定失败。

## 行为

- 真实工具错误产生本轮有效的阻塞证据。模型评估可用且已授权的替代方案后，可调用 `runtime_task_report`，本机据此生成明确的最终说明，结束本轮回复。
- 报告区分缺少认证或权限、暂时不可用、部分交付、后台仍在执行和结果待核对。说明实际原因、可确认的结果、保留内容和下一步。
- 报告只能引用实际错误标识；参数错误、用户正常停止、过期错误或已经变化的前置条件不能冒充当前阻塞。报告不授予权限、不取消下载、不标记用户目标成功，也不替用户换图源。
- 最终说明直接经 Core 原有响应协议生成，无新增上游生成请求、用量回执或虚拟扣费。报告工具仅在有真实阻塞时进入本轮工具目录。
- Core 结束却没有最终答复，或异常结束时，界面会用只读的本机状态生成兜底反馈。状态读取有短暂等待边界，但不会停止模型或下载；无法读取的结果保持未知。
- 连接失联反馈是临时状态，保留原执行及回调身份；重新连接后的真实结果仍可成为最终结论，不能据此重复提交未知操作。
- 已完成状态来自本机任务记录，不代表本轮重新检查了每个文件。提交成功与下载失败或部分交付分别保留；原始日志和敏感地址不复制到反馈中。
- 缺少图源认证的检查提前至坐标系等导出问答之前，避免已知无法取得数据时仍要求填写暂时用不上的参数。
