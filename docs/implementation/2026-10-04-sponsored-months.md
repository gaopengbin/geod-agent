# 赞助渠道按月额度与实际验收

日期：2026-10-04。开发模式候选；正式网关尚未发布，本轮没有安装程序或启用收费。

## 计算与兼容

- 运营配置可选择 `budgetPeriod: "month"`。以服务端 UTC 自然月计算个人及共享 token 预算；界面明确显示 UTC 刷新时间。默认仍为累计计算 `lifetime`，省略新字段不改变旧配置版本。
- 请求按实际预留时间归属月份。跨月后到达的结算、错误核对和重放仍归原月份，历史记录保留；更新配置版本、重新启动服务不会补充当月额度。
- 当前月份与上一期尚未核对的预留分别展示。赞助用量不扣 GeoD 托管额度或钱包；正常开发测试仍为不限额观察模式。
- 原生端校验月份起止和公开字段。过期月份绕过五分钟缓存；打开的模型选择器和渠道页在月份结束时重新读取服务器用量。修复渠道页未订阅刷新事件的问题。
- 日常旧网关没有可选赞助目录接口时，客户端将目录视为空；认证失败、网络异常及其他错误仍保留其真实错误。

运营配置在原有供应方对象中增加：

```json
{
  "budgetPeriod": "month",
  "quotaMode": "enforced",
  "perUserTokenLimit": 200000,
  "totalTokenLimit": 2000000
}
```

以上是示例合作额度，不是当前测试用户限制，也不是供应商账户现金余额。先部署支持月份字段的客户端，再启用月度活动。网关打包须包含新的 `sponsor-budget.mjs`。

## 边界

没有执行真实跨月长期运行、操作系统重启、全新 Windows 安装或公共合作活动。注入时钟回归、真实模型、关闭前台和实际程序重启分别记录。合作方配置、正式发布与钱包收费仍属于后续目标。

完整备份路径和分阶段结果保存在 `restart-state.json`、`prepare-result.json`、`finish-result.json` 和 `restart-processes.json`。正常使用保留原有托管与自有渠道；验收服务与供应商 Key 不作为公共默认渠道发布。
