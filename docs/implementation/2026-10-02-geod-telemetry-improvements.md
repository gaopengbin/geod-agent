## 认证与用户分类

认证代码位于 `G:/code/GIS-AI/geostyle-web/lib/accounts/auth-audit.ts`。GeoD 实例的 `GEOSTYLE_ACCOUNT_DIR` 必须指向 `/srv/laogao/data/geod-studio/accounts`，不能指向微信工具箱的账号目录。共享代码名称不是数据归属依据。

注册、主动登录、Agent 授权码交换、令牌刷新、密码重置分别记录成功或失败。注册自动建会话为独立事件；删除会话不会删除操作历史。审计不记录邮箱、密码、验证码、令牌、Cookie、IP 或原始异常。最多保留 90 天、20,000 条，报表显示采集起点与当前保留起点；审计写入故障不会改变业务返回结果。设置 `GEOD_AUTH_AUDIT_ENABLED=false` 可关闭新记录。

管理员使用身份服务环境运行：

```text
node scripts/manage-accounts.mjs analytics-audience --id <GeoD账号ID> --audience internal
node scripts/manage-accounts.mjs analytics-audience --id <GeoD账号ID> --audience external
node scripts/manage-accounts.mjs analytics-audience --id <GeoD账号ID> --audience unknown
```

没有依据时保留 unknown。浏览器、安装 ID、请求数、不限额配置均不能用于推断分类。模型用量和已知用户的认证历史按当前服务端标签分类；无法识别用户的失败操作归入未分类。

## 下载结果

旧桌面同意通知升至版本 3，用户须重新同意新增范围。监控所有工作流任务状态，报告随机尝试 ID、开始、完整完成、缺块完成、失败、取消、耗时区间、错误类别。暂停不产生新尝试，失败后恢复产生新的尝试。随机 ID 和本地观察状态持久化，避免界面重载重复上报。任务名称、真实任务 ID、路径、坐标、图源 URL 和原始错误均不进入事件。

Agent 账号菜单增加“下载使用统计”，默认关闭。开启后结果关联当前 GeoD 账号；关闭会清除本机各账号待发队列，并停止后续采集和发送，已在途或已入库的事件不会被追溯删除。仅桌面运行时采集，网页预览不采集。

`POST /api/agent/events` 使用已有 GeoD Bearer 鉴权，服务端绑定真实用户并验证预期账号，拒绝切换账号后的错误归属。独立 `agent_events` 表不影响模型 token 用量。只接受 6 个事件字段，每批最多 20 条、16 KiB，限制每账号 120 请求/分钟，最多接受 90 天内及未来 5 分钟的时间戳。事件 ID 与“账号 + 尝试 + 状态”共同去重，入库 90 天后清理。

客户端仅报告同意用户的观测样本，并非完整后台下载账本。断网时保留有限待发队列，超过容量、关闭统计、进程异常或任务在采集前被移除仍可能缺失。耗时为尝试观测的经过时间（含暂停），无法确定时显示 unknown。报表的完整完成率以本期观测开始的同一批尝试为分母，部分完成不当作完整成功。
