# 每轮回复的 Token 统计

## 实现

- 最终回复的复制按钮右侧提供统计图标；悬停或键盘聚焦显示本轮合计、输入、输出、缓存、推理和模型请求次数。对话里不再直接展开统计文字。失败/停止的轮次也保留统计入口与实际用量记录。
- Codex 核心继续负责执行循环。界面读取现有账号隔离的原生执行凭据，将本轮所有请求（包括工具循环和上下文压缩请求）累加，按 generationId 去重。
- 同一回复前的 SDK 续接 runId 合并计算，后台下载轮询不会混入本轮；已结束的下一轮独立计算。
- 旧引擎没有原生 run ledger，因此把实际 generation 用量保存到当前用户轮次，并累加该轮各次请求。
- 缓存输入是输入的子集，推理用量是输出的子集，只在悬停/键盘焦点明细中说明，不再次加到总量。
- 数字来自实际回执。仅部分回执可用时显示“已知用量”；未知记录显示“用量待核对”或“用量不可用”，可只读核对，不重发模型请求。晚到的结算最多自动补查两次。
- 汇总随对话保存；完整用量重新加载时直接读取保存的数据，不再次请求原生凭据。没有可恢复凭据的历史轮次不能反推数字。
- 中英文与深浅色样式沿用现有组件。统计位于最终答案外部，不放入折叠的思考与执行记录。

- UI 验证 9 组通过：中英文 × 深浅色、360px 窄面板、键盘明细、保存后刷新、部分/待核对/不可用/停止/流式状态；模拟桥接拒绝任何模型或钱包写操作，实际模型请求为 0。
