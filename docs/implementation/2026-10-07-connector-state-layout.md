# 连接器未启用状态与卡片布局

- 本机高德连接器已保存且有 Key 配置，但 Agent 的 `extensions_list` 只返回启用项，导致把未启用误报为未接入。
- 前端与无界面执行均返回安全的 `registeredConnectors` 清单，包含注册、启用和认证已配置状态。关闭的连接器可见，不读取工具、不执行网络握手；启用项发现失败也保留已保存状态。
- 按连接器名称查询时优先查询该项，避免为了确认未启用状态而连接其他无关服务。
- `mcp_connect` 可使用已保存的 `connectorId` 准备启用确认卡，复用本机地址和凭据。不会自动启用。
- 更新模型工具说明，要求用最新返回状态区分“已添加未启用”、工具发现失败及未添加。
- 设置页配置 Key 或启用后，旧会话卡同步本机状态，避免已填写 Key 后仍显示填写请求；注册元数据不会被当成网络连接成功证据。
- 卡片保留“查看工具”和“启用/停用”，Key、浏览器授权、移除放入共享浮层菜单。操作行支持受限宽度换行，没有通过裁切隐藏溢出按钮。

验证：15 项发现和接入逻辑测试通过；浅色/深色的 840、580、390、300 像素视口检查按钮不跨出卡片，菜单选择和 Esc 关闭通过。前端与原生均重新构建；实际账号配置只做读取，不自动启用、不改 Key、不调用模型。

证据：`artifacts/connector-state-layout-20261007/`。
