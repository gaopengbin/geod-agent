# GeoD Agent 系统托盘常驻

用户最新确认：最小化保留在任务栏，关闭按钮收起到托盘；托盘菜单提供“打开”和“退出”。

## 实现

- 桌面前台创建一个 GeoD Agent 系统托盘图标；独立后台服务不创建重复图标。
- 自定义最小化按钮调用系统正常最小化，保留任务栏入口；不再监听失焦和尺寸变化来隐藏窗口。关闭按钮和系统关闭请求隐藏窗口并阻止销毁，后台服务保持运行。
- 左键点击或双击图标恢复窗口；右键菜单提供“打开 GeoD Agent”和“退出 GeoD Agent”。再次启动同一应用也恢复原窗口。
- 托盘菜单跟随界面语言，中文与英文分别显示。恢复已有窗口不重新挂载界面，因此不重播启动动画。
- “退出”复用现有维护检查：检查前台 AI、缓存工作以及后台任务，空闲时关闭模型宿主与独立后台，然后退出桌面进程。正在执行任务或无法安全停止时恢复窗口并提示用户先停止任务或等待完成。
- 托盘创建失败时保留正常最小化与关闭，避免窗口隐藏后无法找回。
- 使用现有应用图标，没有增加下载资源。Tauri 启用内置 `tray-icon` 功能。

主要代码：`apps/geod-agent-desktop/src-tauri/src/desktop_tray.rs`。
