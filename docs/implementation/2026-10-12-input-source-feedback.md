# 中文输入与图源预览反馈

## 已修改

- PromptInput 的实时编辑缓冲由浏览器管理，仅在外部草稿改变且没有组合输入时同步。中文拼音组合期间不触发会话草稿重绘、不改变输入框高度；确认后再同步。IME Enter 和旧式 keyCode 229 不发送消息。切换会话重建输入框，避免跨会话残留。
- 开始页动画结束后不再残留 transform/filter，减少原生候选窗定位的干扰。
- 图源预览的配置读取、覆盖查询、瓦片请求、图片解码、磁盘缓存与排队均有超时。超时会释放预览队列名额，卡片显示失败状态和重试入口。
- 手动表单和 Agent 配置共用瓦片模板规范化，支持 `{TileMatrix}/{TileRow}/{TileCol}` 与编码后的已知占位符；普通查询参数不解码重建，认证仍独立保存。
