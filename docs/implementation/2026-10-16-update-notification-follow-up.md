# 下一版：更新提醒与消息中心

用户在 0.2.6 发布过程中确认，下一版补充明显的更新提醒，同时在消息中心保留可点击的版本通知。本次 0.2.6 保持已冻结的构建内容，继续完成发布。

## 交互要求

- 自动检查发现正式新版后，提供包含版本号和更新摘要的明确提醒。
- 消息中心保留对应的版本通知及未读状态，点击后进入现有应用更新页面。
- 同一版本的提醒去重，尊重用户现有自动检查更新设置。
- 下载、签名校验、备份和安装继续使用现有原生更新流程。
- 验证冷启动发现更新、重复启动去重、阅读通知、进入更新页面，以及检查失败后的重试。

## 当前状态

需求已确认，待下一版实施；0.2.6 仍通过账号菜单的“应用设置 / 有更新”提供入口。
