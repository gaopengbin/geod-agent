# 任务修改、确认延续与上游拒绝诊断

## 现场证据

2026-10-16 新用户任务要求在济宁市行政范围获取 Z14 影像和矢量，经历 Google、天地图、Esri 换源。26 次已结算调用合计输入 643,820、输出 23,472 tokens。之后另一个会话连续三次 `UPSTREAM_REJECTED`。

旧下载统计存在一次失败、一次完成，但没有数据类型字段，无法证明影像、矢量两份成果都完整交付。模型声称“矢量计划没有持久化”，并不能证明本机计划实际丢失。

该托管渠道直连 `api.deepseek.com`，不是社区赞助或私人中转。旧网关未保存失败响应的 HTTP 状态、供应商错误分类或请求标识，三次历史拒绝的具体原因无法从现存记录还原；不得推断为余额、限流或格式问题。

2026-10-18 当前渠道独立验证：无效参数获得 HTTP 400，安全分类为 `parameters_invalid`；正常请求 HTTP 200、finish_reason=stop、有完整回复，输入 7、输出 2 tokens。当前健康情况不证明历史故障原因。

## 通用修复

- 原生坐标系选项完成后，用验证过的答案继续同一条提案。其他旧并行调用仍由用户输入门控阻止，用户中途修改、取消仍会终止旧参数。
- 源或层级修改可从属于当前账号、会话的真实原生计划继承已确认 CRS/重采样；核对范围、格式、层级和计划归属。换源产生新计划并重新走原生授权，不继承旧下载授权。
- 同账号、会话、物理工作区和参数完全相同的待处理提案复用原计划。已启动、已清理、图源指纹变化、不同范围参数不复用；矢量/在线/3D 以事务保护去重。
- 每轮实时读取独立的数据任务账本，明确 pending/completed/failed/cleaned 和省略数量。历史列表压缩保留任务 ID、planHash、状态；完整记录可分页读取。不可读表示未知，不冒充不存在。
- 网关保留允许的 HTTP 状态、原因分类、请求结构计数、有限请求标识和重试等待时间；原始错误正文、用户内容、URL、凭证不落库。客户端按已记录原因显示消息，未知时不猜测格式错误。
- 已确定拒绝释放预留且不重复计费；重放同一 generation 不再调用供应商；5xx/结果不确定仍保留待核对状态，不盲目重发。
- 用户同意统计时上报匿名下载类型和原生失败类别。兼容旧服务能力协商，旧客户端/旧记录仍可读取；不上传原生任务编号、位置或文件名。
- 新诊断模块已加入原生适配器嵌入资源和版本散列，安装包不依赖源码目录。
