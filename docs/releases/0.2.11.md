# GeoD Agent 0.2.11

## 边界交付与任务执行

- 已保存的行政区或自定义边界可直接导出 GeoPackage、GeoJSON，并支持合并面；保留孔洞和离散区域。
- 导出后由本机 GIS 引擎重新打开成果，核对坐标系、要素数量、几何和属性，记录校验结果。
- 改善原生导出能力发现，减少重复搜索工具、重建相同计划和已完成任务的重复确认。
- 已完成任务复用前检查文件；清理或丢弃的任务不会被旧缓存错误恢复。
- Census 区域查询同时兼容基础名称与官方完整名称。

## 模型异常与额度

- 网关补充流解析、消息结构、工具协议和模型结果阶段的脱敏诊断。
- 无法使用的工具返回、畸形结果或缺失用量结果不再持续占用用户预留额度；上游成本不确定时保留未知记录。
- 改善相关中文错误提示，继续保留 Codex 核心和有进展任务持续执行的机制。

GeoD Agent 持续开源，支持自有模型渠道。

## English

- Export saved boundaries directly to GeoPackage or GeoJSON, with polygon dissolve and preservation of holes and disconnected parts.
- Reopen exported datasets with the managed local GIS engine and verify CRS, feature counts, geometry and attributes.
- Improve export discovery, semantic task reuse and completed-task confirmation handling; validate files before reuse.
- Support both base and official Census area names.
- Add sanitized upstream protocol diagnostics and release customer reservations for unusable model results, keeping uncertain provider usage explicitly unknown.
