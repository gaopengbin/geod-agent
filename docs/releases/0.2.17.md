# GeoD Agent 0.2.17

- 改善托管模型的工具兼容性。旧会话保留历史工具执行结果，恢复时只允许调用当前可用工具。
- 影像任务中断时保留最后一批瓦片进度。恢复原任务时核验并复用已有缓存，收到图源限流后错开请求。
- 影像连接错误可区分超时、DNS、TLS、代理和响应读取中断。矢量和 3D 下载显示实际失败阶段、图源和 HTTP 状态，便于重试或检查凭证。

## English

- Improve hosted tool compatibility when continuing chats that used older connectors. Historical results remain available as context.
- Retain the latest imagery progress at interruption, validate cached tiles on resume, and pace requests after rate limiting.
- Show more specific imagery connection errors. Vector and 3D tasks report the observed stage, source, and HTTP status when available.
