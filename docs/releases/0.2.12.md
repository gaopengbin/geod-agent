# GeoD Agent 0.2.12

## 首次登录与授权恢复

- 首次注册、收验证码及浏览器授权的等待时间从 2 分钟延长至 10 分钟。
- 等待授权时可直接点击“重新发起授权”，建立新的登录回调，无需关闭并重开软件。
- 超时后提供明确的重新登录提示；返回应用时及时刷新授权状态。
- 隔离旧授权请求：迟到的回调、失败或超时不会覆盖新的登录状态和账号凭据。
- 若授权已经成功但界面尚未刷新，重试会采用已保存的有效账号，不再要求退出后重新登录。

本次升级保留已有登录凭据、工作区、会话、下载任务及成果文件。GeoD Agent 持续开源，支持配置自有模型渠道。

## English

- Allow ten minutes for first-time registration and browser authorization instead of two.
- Restart browser authorization directly from the waiting screen without restarting the application.
- Provide an actionable timeout message and refresh sign-in state when returning to the app.
- Prevent superseded callbacks, errors and timeouts from overwriting a newer login or its credentials.
- Adopt an already completed sign-in when retrying instead of requiring the user to sign out first.

Existing credentials, workspaces, conversations, download tasks and delivered files are preserved. GeoD Agent remains open source and supports your own model providers.
