# GeoD Agent 0.2.1 测试版

下载：[GitHub Release](https://github.com/gaopengbin/geod-agent/releases/tag/v0.2.1)。仓库为私有仓库，需要具有访问权限的 GitHub 账号。

## 本次更新

- 新用户体验额度：首次登录并启用 Agent 钱包自动到账 **20,000 Credits**。每个 GeoD 账号只领取一次；换设备、重复登录、并发及网关重启不重复发放。
- 赠送余额支持托管模型的预留、实际用量结算和中断恢复。无需先开启充值，赠送优先于付费余额消费。
- 余额页显示真实赠送记录，支持中文/英文和明暗外观；体验钱包隐藏未开放的套餐预览，窄窗口保留完整刷新按钮。
- 可停止新赠送并保留已到账余额。既有无限测试配置保持原状态。

`1,000 Credits = 1 元 GeoD AI 计费余额`。自带模型 Key 不扣此钱包，本机数据处理和下载不收取模型费用。

## 使用与边界

- 安装包与便携包均为 Windows x64；使用方式和八组本机运行资源与 [0.2.0](https://github.com/gaopengbin/geod-agent/releases/tag/v0.2.0) 一致。
- 配套 Linux 网关包含自动赠送能力，供维护者部署，不需要普通桌面用户运行。
- **2026-10-04 正式网关已更新，新用户首次启用 Agent 钱包可自动领取额度。** 正式 GeoD 登录、20,000 Credits 到账、真实 DeepSeek 流式工具请求与实际用量扣费均已验证；重复请求和网关重启不会再次发放或重复扣费。仍可使用自定义模型渠道，本地不限额开发配置保持原状态。
- 充值、真实收费、签名自动更新及全新 Windows 验收仍未启用或完成。

## 验证

网关 74 项回归、前端 152 项回归通过，3 项配置相关用例跳过；类型检查和生产构建通过。赠送专项涵盖多进程并发、数据库回滚、重启、身份验证、重复领取、用量扣费、停止赠送和赠送/付费余额兼容。隔离界面通过真实 HTTP 和 SQLite 读取验证，中英文、明暗外观及 390px 布局通过。
