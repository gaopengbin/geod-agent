# GeoD Agent 0.2.10

Windows x64 正式更新，2026-10-21。

## 完善 Agent 使用统计

- 补齐官网中英文 Agent 页各安装包入口的点击统计，分别记录版本和官网 / GitHub 渠道；不把点击视为传输或安装完成。
- 在用户开启现有 Agent 使用统计后，记录该账号首次观测到客户端运行。服务端保留期内去重，升级用户不会被冒充为新安装用户。
- 完善 Agent 专用漏斗报表：共享注册、Agent 授权、托管及自有渠道调用、首次上报下载完成分别展示。
- 排除已确认主账号与标记的测试账号，支持内部网页访问标记；未标记匿名访问仍明确保留统计限制。
- 没有采集、尚未开始观测和无法关联的数据继续保持未知，不回填虚假的历史，不计算没有依据的全链路转化率。

统计仍默认关闭，账号之间互不继承；不上传对话、密钥、渠道地址、坐标或文件路径，不扣 GeoD Credits。
