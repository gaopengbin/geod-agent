# GeoD Agent 0.2.0 测试版

本轮以发行收尾为目标，发布首个 Windows x64 测试版。GitHub 标签为 `v0.2.0`，标记为预发布；尚未完成的规划留到后续版本。

下载入口：[GitHub Release](https://github.com/gaopengbin/geod-agent/releases/tag/v0.2.0)。当前仓库为私有仓库，需要具有访问权限的 GitHub 账号。

## 本版范围

- 通过 Agent 配置图源，支持密钥输入、缩略图，以及已验收的影像、矢量和三维数据下载。
- OpenLayers 二维地图与 Cesium 三维场景操作，范围选择、成果加载和任务列表。
- 本地矢量范围、文档、图片、OCR 与音频输入；数据库连接和读取。
- 后台下载、后台命令、本机 AI 定时任务及中断恢复。
- 会话搜索、管理、分支、并行会话、备份，以及中文/英文界面。
- 自有模型渠道、四种模型接口和本机插件/MCP。供应商实际可用范围见[验收清单](../implementation/2026-10-04-product-gaps.md)。
- 左侧提供定时任务统一入口和模型渠道入口；新对话按钮仅在悬浮或操作时反馈。
- 图源缩略图持久化缓存，重开应用后复用；修改图源版本、刷新及损坏时重新获取。
- AI 余额使用 Credits：`1 元 GeoD 计费余额 = 1,000 Credits`，账号入口、预留及用量明细统一显示；测试账号显示无限额度。

测试模式不要求充值。收费与套餐尚未启用。

## 安装与试用

Windows x64 发行构建目录：`artifacts/release-candidate-0.2.0-github-20261004`，包含 RC2 后的全部界面修订。

1. 从 Release 下载 Windows x64 安装包，或者完整解压便携 ZIP 后打开 `geod-agent-desktop.exe`。
2. 使用 GeoD 账号登录；打开左侧“模型与渠道”，配置自己的模型服务和 Key，再从输入框的模型菜单选择该渠道。
3. 添加范围或描述需求，通过对话生成计划；待确认任务在右侧任务区处理。

安装包与便携 ZIP 各约 650 MiB，实际大小以 Release 为准；随包提供八组本机运行资源，无需另外安装 Node、Python 或 Codex。音频转写模型首次使用时单独下载。桌面显示需要 Microsoft Edge WebView2，安装程序会检查并引导安装。

**默认 GeoD 托管模型仍需同步配套网关。** 本机网关和自有渠道已有验收记录，当前版本建议先使用自己的模型渠道。此限制仅针对默认托管模型，Release 标记为测试版；收费、自动发放体验额度及正式签名更新渠道尚未启用。

## 验收与暂缓项

此前独立程序实际读取 PDF 和数据库、调用地图、关窗后台执行、完整重启及备份通过；RC2 资源摘要通过。新增的 Credits、导航及缩略图缓存已经开发桌面和隔离界面验收，原有会话与连接保持一致。本次发行另行构建并核对安装包与便携包资源，不复用旧候选的校验值。

全新 Windows、真实系统重启和正式签名更新渠道尚未验收。真实收费、账单分页/CSV、其他供应商逐项接入及剩余规划不列为本次发行完成条件。
