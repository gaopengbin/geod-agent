# GeoD Agent 0.2.5

Windows x64 更新，发布日期：2026-10-14。

## 对话与输入

- 对话采用紧凑的 Codex 式执行记录：相邻工具操作分组，完成后收起，最终回复独立显示；查看历史时保持阅读位置。
- AI 仍在回复时，会话列表显示加载状态；完成且未读的回复显示蓝点。
- 修正中文组合输入期间的草稿重绘、高度变化和 Enter 误发送，减少输入法候选窗定位干扰。
- 在未使用的新会话重复点击“新对话”时复用当前会话，保留草稿、附件与选择范围；有内容或正在执行的会话仍独立创建。
- 上下文设置改为折叠区域，减少“模型与渠道”页面的卡片占用。

## 启动与任务管理

- 初始 HTML 直接提供本地品牌开屏，原生窗口在首屏就绪后显示，改善启动先出现空白窗口的问题。
- 新会话没有历史计划时不再提示“恢复工作区”；真正的历史任务继续核对账号、会话与保存的工作区。
- 调整新会话首页的位置。
- 支持单项和批量清理任务、丢弃未启动计划，以及从“已清理”列表恢复；保留成果、缓存、审批与执行证据。运行中的任务和已启用的定时模板需要先停止。
- 补齐任务清理工具的运行策略登记，保持参数校验和原生归属检查。

## 图源与网络

- 手动图源与对话配置共用瓦片模板处理，支持已知的编码占位符及 TileMatrix / TileRow / TileCol 别名，保留普通查询参数。
- 图源缩略图增加超时释放与重试，避免一个无响应请求持续占住预览队列。
- Esri World Imagery 预设调整服务主机；现有手动图源不自动改写。
- 下载网络失败提供连接检测和代理设置入口，实际下载日志区分系统代理来源与 DNS、TLS、连接、超时等脱敏原因。检测和任务重试不调用模型、不消耗 AI Credits。

## 模型兼容与更新

- Responses 渠道保留历史推理与消息、工具调用的必要配对，修正 Luna 多轮请求兼容问题；供应商拒绝与未知请求结果按真实回执显示。
- 安装包和更新文件接入腾讯云国内 CDN，保留 GitHub 下载备用入口。
- 新更新器支持复用未变化的运行环境，只下载变化、缺失或损坏的组件；各组件和应用更新包独立校验签名、版本、字节数与 SHA-256。
- **0.2.4 及更早版本首次升级到本版仍下载完整包。** 使用本版之后的更新才可复用组件；首次安装继续提供完整安装包与便携 ZIP。应用程序仍整体更新，未采用主程序字节级差分。

## 验证范围

发布前检查前端、原生任务与更新分发回归，核对正式签名身份和实际安装包载荷。中文输入、首次未保存代理下载、任务清理恢复、启动首屏和对话界面的本地检查记录见 `docs/implementation/2026-10-12-*` 至 `2026-10-14-*`。

验证环境为当前 Windows 开发机及隔离配置。反馈用户机器上的输入法问题和“保存自动代理后恢复下载”的原始失败未取得完整复现证据，不能将本机成功视为所有电脑都已解决。任务清理只管理列表记录，不删除成果或释放磁盘空间。更新签名不等同于 Windows Authenticode 发行者证书。
