# GeoD Agent 0.2.8

Windows x64 正式更新，发布日期：2026-10-20。

## 跨工具任务记录与局部恢复

- 多工具交付可在运行层持久化步骤、依赖、实际参数、执行回执和验收条件。保留现有 Codex 核心，不以固定调用次数截断有进展的任务。
- 中断后核对现有步骤与本机成果，复用仍然有效的下载和已确认参数；只修复失败步骤及其依赖。结果未知的写操作先核对原回执，不直接重发。
- 支持局部修复验收条件和追加后续步骤，避免为了继续转换而重建整张计划。旧会话可通过兼容入口发现运行层工作流工具。

## 本机成果验收

- 文件、JSON、栅格和矢量成果由本机检查。COG 可核对坐标系、布局、压缩、概览和真实数据块，而不是仅凭模型回复判定完成。
- 统一直接工具、MCP 与网关的数据库筛选参数契约，减少字段与筛选条件不一致。
- 明确 MCP 回执解包后的验收结果和指针路径；缺少实际判定条件时提前提示，错误路径保留字段层级提示，不靠重复执行操作来试探。

## 断连后的继续入口

- 修复“服务端确认请求未到达、本机会话已空闲，但继续入口仍锁住”的情况。
- 原请求仍在执行、网络状态不明或待费用核对时继续保留证据，不将连接失败当作已完成，也不自动重发未知副作用。

## 验证边界

数据库到 COG 的真实开发版演示完成两份 Esri 影像与 COG 交付；中断后 8 个已完成步骤回执和原影像指纹不变，未新增下载或计划。演示含真实模型断连、初始坐标系选择及一次人工验收接口提示，不能据此宣称所有任务全程无人干预。该次演示后的路径说明改进另有专项回归。

本版不保证所有上游连接不会断开；历史会话的成果可用性仍以本机实际文件和原生记录为准。发布校验不重复下载收费 CDN 的完整安装包。

本次桌面回归 374 项、实际 Codex 核心回归 40 项、网关回归 111 项通过。桌面回归另有 22 项可选原生测试未启用；两个既有目录联接测试在 Windows 创建联接时遇到 EPERM，未执行到产品代码，已保留失败日志并单独列为环境限制，不宣称全套无遗漏通过。
