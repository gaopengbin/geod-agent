# GeoD Agent 0.2.14

## 规划条件与任务恢复

- 修复同一坐标系与瓦片格式冲突反复规划的问题。按实际生效的参数保存冲突，重开后继续复用；只有真实用户明确修改条件后才重新规划。
- 复用已保存的条件确认卡，保留图源、范围、级别、导出设置及工作区。一次任务选择不会变成会话默认，也不会授予下载权限。
- 大范围整瓦片请求在用户同意拆分后，可由本机按整数网格生成完整分片计划；继续处理时复用原计划，整体空间预算不足时明确说明后续选择。
- 后台启动失败保留启动阶段与系统诊断，避免换工具反复拉起同一个失败后台；明确恢复成功后重新刷新状态。

## 图源、数值与反馈

- 图源检查读取 WMTS 服务公布的模板、矩阵和时间目录，减少重复探索和猜测接口地址。
- 为公开浮点 ImageServer 提供独立的数值栅格交付通道，冻结已选函数、目录项与时期，并核验浮点类型、坐标系及文件摘要。已验证的 VIIRS 月度样例保留原始数值，预览图与分析文件分开。
- 修复流式 UTF-8 分块边界损坏中文历史内容的问题，改善工具目录和已读上下文复用。
- 模型空答复与下载状态分开反馈；已有成果保留，不因回复未完成而误报下载失败。
- 本机下载诊断区分未授权、未观察到下载、排队、发送异常与已确认上报。统计失败不阻断下载，收到回执后才清空待发事件。

## 验证范围

真实模型已验证：同一条件不重复规划、明确修改后放行、重开保留条件、E 盘完整分片与容量预检。真实数值下载验收为选定公开服务的北京市 VIIRS 月度样例；可用时期、函数、范围及资源容量以提供方和本机检查为准。

全球全量下载、翻转成品与所有图源的数值交付没有作为本版通过项。容量预算不是实际传输大小。升级保留原有会话、任务和成果。

GeoD Agent 持续开源，支持配置自己的模型渠道。
