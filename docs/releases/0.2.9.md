# GeoD Agent 0.2.9

Windows x64 正式更新，发布日期：2026-10-21。

## 可选择的 Agent 使用统计

- 新增独立“Agent 使用统计”开关，默认关闭、按账号保存；旧下载统计授权不会自动扩大为模型统计授权。
- 开启后，原生后台可记录当前活跃会话、自有模型渠道请求的开始与结果，以及供应商确实返回的输入/输出 Token；未知用量保留未知。
- 统计不会上传对话、模型名称、渠道地址或 ID、密钥、文件路径和坐标，不进入 GeoD 收费账本，不扣 Credits。
- 本机待发送队列支持断网后重试、重复上报去重及账号隔离；关闭时清除待发送数据，已发出的请求可能完成。网络上传不持有模型记录库的写锁。

## 下载统计与运营报表

- 下载统计保持单独、自愿开启，使用原生后台的持久化任务结果；影像及其他数据下载分别统计。
- 新增 Agent 专用只读报表，将账号注册、桌面授权、托管/赞助模型、自有渠道及下载结果分别展示。
- 排除已确认的主账号与标记为内部测试的账号；缺失埋点和未开启统计不会伪装成零使用量。
- 不回溯上传旧会话和此前未采集的历史。旧客户端及未开启统计的操作仍可能无法观测。
