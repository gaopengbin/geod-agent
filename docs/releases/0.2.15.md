# GeoD Agent 0.2.15

- 下载失败诊断现在区分图源服务、底图与注记、实际 HTTP 状态和失败阶段。
- 空间检查按实际文件系统分别记录成果、临时文件与缓存所需及可用空间；修正缓存路径持久化问题。
- 增加自愿开启下载诊断的入口，以及等待上报、授权或网络异常的状态反馈。
- 后台从持久化任务记录补采结果，保留失败尝试与后续成功尝试各自的诊断，核对接收回执后再清理待发送记录。

诊断不上传密钥、坐标、文件名或完整路径。未开启统计或旧版本未上报的历史结果仍为未知。

已用内部测试账号验证真实高德底图、注记下载，受控注记 HTTP 403，以及线上接收和测试数据排除。受控错误不代表已复现用户当时的图源拒绝；用户外接 E 盘环境未在本机复现。
