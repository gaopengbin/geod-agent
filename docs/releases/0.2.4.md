# GeoD Agent 0.2.4 测试版

发布日期：2026-10-11。Windows x64 公开测试版。

## AI 对话与任务执行

- 工具、技能目录、详细业务规则和旧历史按需加载。已确认参数、接受的方案、未完成操作与当前任务状态保留；旧原文可分页取回，重启后仍可恢复。
- 保留现有 Codex 核心，不默认按 12 次调用截断长任务。运行层根据真实进展、重复失败与权限决定继续或停止；托管模型余额为正时允许提交，余额用完后停止。
- 后台下载等待和完成登记由原生运行层处理，避免模型反复轮询或仅为登记完成再调用模型。
- 继续任务、重试与仅调整缩放等级时沿用同一任务已确认的坐标系。不会把单任务选择自动升级为会话默认。
- 每轮回复的复制按钮旁增加统计入口，可悬浮查看实际输入、输出、缓存和推理 token；缺少回执时明确显示不可用。
- 大段坐标与路线以本机引用进入模型，完整工具记录保留。可选 RTK 精简部分成功命令输出，不改变权限，失败与未知格式保留原结果。

## 对话界面与工作区

- 合并同一轮的「思考与执行」，最终总结显示在执行记录之外，超长思考限制高度并支持滚动。
- 已回答问题卡在完成后收起；对话只保留任务成果总结卡，详细任务和成果在右侧面板查看。
- 修复回复完成后的滚动、面板拖动期间的响应与宽度适配，以及历史状态导致的重复忙碌或过期「等待确认」提示。
- 保留实际任务结果和新鲜原生状态，避免将旧模型回复当成当前审批或完成证据。

## 登录、外观与托盘

- 独立登录页、中文和英文开屏动画、GeoD Agent 专用蓝紫渐变 G 图标。
- 最小化保留在任务栏；关闭窗口收起到托盘。托盘提供「打开」和「退出」，后台任务继续运行。
- 登录状态变化同步到界面，网络故障与确实需要重新登录分别处理。

## 下载与按需 GIS

- 支持明确选择 EPSG 坐标系并执行重投影。下载、拼接裁剪与核验分别显示状态；瓦片达到 100% 不等于成果已经完成。
- 默认不压缩、不构建金字塔；可直接打开成果目录。
- 多格式范围导入、矢量转换、矢量分析、栅格检查和栅格转换分别按需安装，固定版本及 SHA-256 校验，共享依赖并支持离线目录。
- 基础包移除 Java、Tika、Apache POI 和本地 OCR。基础范围导入仍支持 WGS84 GeoJSON、手绘范围和行政边界。
- 高德 / Mapbox 连接器配置按明确操作触发，避免无关操作反复弹出。

## 验证范围

桌面和网关回归、原生参数和任务状态、完整历史恢复及真实 Core 工具循环均有检查记录。真实 DeepSeek 故宫影像任务沿用原边界、Esri Wayback release 63116、Z16、GeoTIFF / EPSG:4326，下载和最终总结完成，9 个瓦片无缺失，成果校验值与原版一致。

该同任务历史实测输入从最初 311,387 降至 73,502 tokens。缓存命中和模型输出会变化，这不是对所有任务或新用户首次费用的承诺。详细回执见 [上下文分层实测](../implementation/2026-10-10-context-tiers.md)。

全新 Windows、全部图源和外部服务的验收仍未完成，本版继续标记为测试版。扫描文件不自动视为 OCR 已识别；旧 Office 二进制格式请先转换为现代格式。正式现金充值尚未开放。
