# GeoD Agent 0.2.4 — 本地发布候选

状态：**当前代码已提交，本次改进尚未发布。** 官网与 README 在本地整理，公开下载安装包仍为 0.2.3。用户要求先提交和预览，确认后再发布。

## 本次改进

### 下载与成果

- 支持指定目标 EPSG 坐标系，必要时下载后重投影；未明确时显示选择卡。
- 仅修改缩放等级时，从当前会话实际拥有的计划继承已确认坐标系，不重复询问。不会自动改变会话默认或启动下载。
- 下载、拼接裁剪和核验显示不同阶段；生成成果期间持续显示状态，瓦片 100% 不代表任务已完成。
- 默认不压缩，不默认构建金字塔；任务与成果页可打开成果目录。
- 图源缩略图使用持久化缓存；数据与参数是否可用仍由真实工具结果判断。

### GIS 按需安装

- 基础资源移除 Java、Tika、Apache POI 与本地 OCR。
- 五项 GIS 技能分别安装：多格式范围导入、矢量转换、矢量分析、栅格检查、栅格转换。
- 下载与解包校验固定版本和 SHA-256，共享已下载依赖；支持离线目录。
- 缺少技能时提供安装提示，确认后继续原操作。
- 基础包仍支持 WGS84 GeoJSON、手绘范围、行政边界和瓦片下载拼接。

### 对话与连接器

- 待回答选择卡持久保留在会话中，可稍后重新打开；已回答卡可查看选择。
- 独立登录界面继续采用浏览器账号授权；同步官网头像与昵称。
- 已保存、未启用与已启用的连接器状态可区分；首次启用与连接目标解析改进。
- 高德 / Mapbox 配置表单按明确操作触发，避免无关操作反复弹出。
- 折叠执行记录时仍显示活动状态；超长思考有最大高度与滚动区域。
- 输出上限及未完成轮次明确说明；继续任务沿用已确认参数。
- 大段坐标和路线使用本机文件引用与摘要进入模型；原始工具记录保留。
- 可选 RTK 对部分成功命令的输出做摘要。失败、运行中、未知格式或不可用时回退原始结果；不改变执行权限或命令，不承诺固定费用节省。

### 产品资料

- 中英文 README：使用流程、能力表、实际截图、版本状态和文档入口。
- 官网新增独立 Agent 产品页和首页入口，保留现有账号头像、昵称与应用入口。
- 中英文官网路由、语言切换与账号返回路径已在本地合并；公开版与候选改进分开标注。
