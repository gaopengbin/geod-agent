# GeoD Agent 0.2.6

Windows x64 正式更新，发布日期：2026-10-16。

## 历史任务与恢复

- 历史任务提示增加“检查并恢复”入口，区分工作区关联缺失、记录缺失、任务归属不符和数据读取失败，并给出对应操作。
- 支持重新关联原工作区，以及从匹配的本机升级备份补回缺失的计划、审批、已结束任务和进度记录。恢复前保存账本快照，校验备份与账号、会话和工作区归属，不覆盖已有记录，不自动恢复下载执行。
- 找不到可用备份时提供原成果文件夹和诊断信息入口；诊断不包含对话正文或服务密钥。缺失的历史引用仍保留，可在原记录重新可读后恢复关联。
- 修正工作区检查失败时把默认文件夹写回历史会话的问题。记录恢复不调用模型、不重新下载数据。

## 对话、停止与追加消息

- 优化执行活动分组、完成折叠、详情过渡和阅读位置，完成的最终回复独立显示。
- 回复进行中可排队追加文字、图片和文档，并支持预览、编辑、删除和排序；确认送达后才从队列移除。正常停止使用中性状态，保留并暂停待发送消息。
- 原生执行账本保存流式事件、回调认领和消息回执；断开后恢复原执行订阅，避免重启模型或重复派发已经执行的工具。
- 窗口缩放和内部分割线共用会话最小宽度规则，避免聊天区域被挤得过窄。

## 附件、审批与数据下载

- 图片、文档统一列出已提交附件；读取图片时提供真正的图片内容。文本模型遇到图片会明确提示兼容性问题。
- 工具目录明确查询范围、分页结束和精确名称匹配，减少重复探索；任务状态和文件读取保持实时。
- 逐项确认模式下，工具等待本机具体计划的审批和启动结果，确认后继续原执行；等待期间不反复调用模型。
- MVT 下载支持本机凭证库中的认证请求头和查询参数，用于需要授权的 Mapbox 等矢量服务。公开计划只保存连接引用和版本，服务密钥不经过模型。
- 下载使用统计改由本机后台持久化队列处理，涵盖影像、矢量、在线导出与三维任务；保持默认关闭和主动开启要求。

## COG 与 Windows 兼容

- 修正 COG 转换的概览参数处理，保留用户指定的概览重采样与级别，并增加成果核验。
- 修正 Windows 映射目录下桥接入口误判导致进程静默退出的问题，保留现有 Codex 核心。

## 验证范围

完成前端、原生任务、恢复与分发检查，并核对更新签名、安装包载荷和公开更新入口。本机真实模型复验覆盖历史 Landsat 影像与 Mapbox 建筑矢量下载，成果文件已核验；其中 Landsat 成果为真彩色 RGB 渲染，不是原始反射率多波段数据。

恢复逻辑使用隔离 SQLite 备份验证所有权、完整性、冲突回滚和不重启下载；界面故障场景使用受控数据。既有真实会话的 6 项已完成任务与对话在开发版重启后保持完整。没有通过删除真实用户记录来测试恢复，也未完成全新 Windows 环境和所有外部供应商的穷尽验证。更新签名不等同于 Windows Authenticode 发行者证书。
