# GeoD Agent 0.2.7

Windows x64 正式更新，发布日期：2026-10-18。

## 任务确认与换源

- 坐标系选择完成后继续当前提案，减少同一参数反复确认和重新规划。
- 修改图源或层级时，依据当前真实任务保留已确认的范围、格式、坐标系和重采样设置；图源或下载参数变化仍核对新的原生计划。
- 相同账号、会话和工作区内，参数相同的待处理计划可复用。已开始、已清理、参数或图源配置已变化的任务不会被误复用。

## 长任务与状态恢复

- 每轮补齐矢量、在线导出和三维任务的原生状态，减少误以为已有计划不存在而重复创建。
- 历史上下文压缩保留任务编号、计划指纹和状态；省略记录有明确数量，完整原记录仍可按需读取。
- 保留现有 Codex 核心与原生授权检查，不通过限制模型调用次数截断有进展的任务。

## 错误诊断与下载统计

- 网关记录上游 HTTP 状态和安全原因分类，区分认证、余额、限流、上下文、消息、工具和参数问题；不记录供应商原始错误正文、用户内容或凭证。
- 客户端按确切原因提示；未知原因不再猜测为格式问题。同一已拒绝请求的状态重放不会重复调用或扣费。
- 主动开启使用统计后，匿名下载结果可区分影像、矢量、在线和三维任务，并保留原生失败类别。统计默认关闭，不上传位置、文件名或本机任务编号。

- GeoD Agent 继续开源，支持接入自己的模型渠道。

## 验证边界

通用修复完成 693 项本地回归和真实渠道小请求验证。原生测试另有 22 项可选项目忽略，一项既有 Windows 登录刷新竞争测试挂起后单独排除；未声称全套无遗漏通过。历史三次上游拒绝因旧版记录缺失，无法补还具体原因。

本版未重新下载整个城市或代替用户核验本机全部历史成果；未完成全新 Windows 环境的穷尽验证。更新签名不等同于 Windows Authenticode 发行者证书。
