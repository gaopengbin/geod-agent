# GeoD Agent 0.2.13

## 谷歌历史影像

- 在对话中指定地点和历史截止日期，查询 Google Earth 的真实历史目录，登记固定版本，再沿用本机计划确认、下载、裁剪和 GeoTIFF 导出。
- 历史版本按截止日期或之前选取，成果附带逐块目录日期、提供方署名和内容摘要；不把目录日期当作整个区域同日拍摄的证明。
- 暂停与恢复复用同一任务、已批准的计划和已下载内容。没有覆盖时明确说明原因，不生成空白文件充当成功。

## 窗口响应与任务恢复

- 修复同步登录检查、网络和授权锁等待拖住窗口操作的问题，原生等待移到后台，本机任务读取不再先等待联网刷新。
- 未提供的本机操作和异常退出会明确反馈，避免界面一直等不到结果；远程模型和支付请求继续使用服务器授权。
- 改善首次使用的附件、图源认证和导出前置条件处理，保留已确认的范围、坐标系、格式及任务状态。
- 修复用户补充要求、换源与中断恢复时的状态复用，减少重复探索、重建计划和重复确认。
- 无法继续、部分完成、后台执行和结果未知分别反馈；已有成果保留，结束回复不取消下载。
- 任务详情优先显示裁剪后已核验成果的实际尺寸，尚未生成成果时明确显示瓦片网格尺寸。

本次升级保留登录凭据、工作区、会话、下载任务及成果。历史影像验收包含故宫附近截至 2010 年的真实下载、GeoTIFF 坐标与像素核验、暂停恢复和无覆盖反馈；可用时期与覆盖仍以图源实际返回为准。

GeoD Agent 持续开源，支持配置自己的模型渠道。

## English

- Query real Google Earth history dates from a conversation, pin a historical snapshot, and download, crop and export it through the existing local imagery workflow.
- Select imagery on or before the requested cutoff. Retain per-cell history dates, provider credits and content hashes without presenting index dates as verified acquisition dates for an entire region.
- Resume the same approved task and reuse downloaded content. Report missing historical coverage instead of publishing a blank result as success.
- Keep synchronous sign-in, network and credential-lock waits off the window thread. Reading local tasks no longer waits for an online token refresh; remote model and payment requests retain server authorization.
- Give explicit feedback for unsupported local commands, unexpected outcomes, blocked work, partial delivery and still-running tasks.
- Preserve confirmed inputs and native task state across prerequisites, amendments, source changes and recovery, reducing repeated discovery, planning and confirmation.
- Show verified cropped result dimensions when available, and label planned tile-grid dimensions separately.

Existing credentials, workspaces, conversations, download tasks and delivered files are preserved. Verification includes a real historical download near the Forbidden City, GeoTIFF coordinate and pixel checks, pause/resume and unavailable-coverage handling. Available periods and coverage depend on the source.

GeoD Agent remains open source and supports your own model providers.
