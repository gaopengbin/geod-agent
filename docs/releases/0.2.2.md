# GeoD Agent 0.2.2 发行说明候选

审阅稿，尚未发布。产物、验证依据及未完成的发行门槛见 [整合候选](../implementation/2026-10-05-payment-history-release-candidate.md)。

## 相比 0.2.1 的更新

- 完整用量记录：按时间筛选、分页浏览和导出全部 CSV，包含实际费用、模型用量与原费率记录。
- 完整订单和退款记录：与当前 GeoD 账号绑定，支持时间筛选、分页及全量 CSV。现金充值仍关闭；这些能力不代表已开放付款或退款。
- Windows 安装向导支持简体中文和英文，实际欢迎页及取消退出已验证；初始语言选择框沿用 NSIS 的英文提示，安装与升级阶段仍待验收。
- 更新候选内嵌固定 HTTPS 地址和更新公钥。双语安装包已独立通过下载、版本绑定、签名拒绝和实际资源核验；正式更新渠道尚未启用。

## 额度与数据

继续沿用每个新 GeoD 账号一次的 **20,000 Credits** 赠送，`1,000 Credits = 1 元 GeoD AI 计费余额`。本版没有调整赠送或模型费率。自带模型 Key 的调用不扣此钱包；本机数据处理和下载不收取模型费用。赞助入口继续隐藏。

旧网关暂未提供完整记录接口时，客户端会明确提示不可用，不显示伪造数据。正式只读接口上线须在发布前另行确认。

## 验收范围

Windows x64 安装与免安装包、配套 Linux 网关分别保留固定摘要。正式账本副本的本机升级、回退及再升级通过，原有请求、用量、赠送和余额保持。现金付款/退款、正式 HTTPS 切换、安装升级/回滚、真实系统重启及全新 Windows 仍有未完成的验收；多小时后台测试尚在运行。

更新签名用于验证更新包，尚不等于 Windows Authenticode 代码签名。

## English

This is a release review draft and has not been published. See the [integrated candidate](../implementation/2026-10-05-payment-history-release-candidate.md) for artifacts, evidence and release gates.

### Changes from 0.2.1

- Complete usage history with date filters, pagination and full CSV exports, including costs, model usage and the original pricing record.
- Account-owned order and refund history with filters, pagination and complete CSV exports. Cash checkout remains disabled; this does not enable real payments or refunds.
- The Windows installer supports Simplified Chinese and English. Both welcome pages and cancellation have been verified. The initial language picker retains NSIS's English prompts; installation and upgrade stages still await acceptance.
- The update candidate embeds a fixed HTTPS endpoint and update public key. The bilingual package passed independent download, version binding, signature rejection and actual payload checks. The production update channel is not active.

### Credits and boundaries

The one-time **20,000 Credits** grant per new GeoD account continues. **1,000 Credits represent CNY 1 of GeoD AI billing balance**. This release does not change the grant or model rates. Calls using your own model key do not debit this wallet. Local data processing and downloads do not incur model fees. Sponsor entries remain hidden.

If an older gateway lacks the history endpoints, the client reports that they are unavailable. Production history routes still require release approval.

An isolated upgrade, rollback and second upgrade of copies of the production ledgers preserved existing requests, usage, grants and balances. Real cash operations, production HTTPS switching, installer upgrades and rollback, a real system restart and a fresh Windows system still have outstanding acceptance work. The multi-hour background test is still running. Update signatures are distinct from Windows Authenticode signing.
