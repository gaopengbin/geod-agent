# GeoD Agent 0.2.3 测试版

本版补齐签名在线更新通道和应用内消息中心。源码仓库维持私有权限，更新安装包通过 GeoD 的 HTTPS 地址提供，不要求客户端持有 GitHub 凭据。

## 本次更新

- 应用更新：在账号菜单的「应用设置」中检查版本、下载更新并校验更新包签名。安装前检查后台任务并创建本地备份，运行中的任务会阻止安装。发行版的更新地址和公钥在构建时固定，模型回复不能替换更新源。
- 消息中心：标题栏右上角铃铛查看产品更新、服务公告和账号通知；支持未读筛选、展开即已读、全部已读、中英文和明暗外观。重要消息提示一次。
- 消息发布：支持草稿、发布、撤回、指定 GeoD 账号、版本区间和生效/过期时间。服务端按账号持久化已读状态；断网时可查看本机缓存。发布工具为维护者服务器上的 CLI，普通用户没有公告写入接口。
- 标题栏拖动区域恢复普通鼠标指针。

## 使用与边界

- Windows x64 安装包地址：`https://geod.laogao.xyz/agent-updates/windows-x86_64/0.2.3/GeoD%20Agent_0.2.3_x64-setup.exe`。
- 更新清单：`https://geod.laogao.xyz/agent-updates/windows-x86_64/latest.json`。
- 旧的 0.2.0/0.2.1 客户端没有启用更新源，需要先手动安装此版；后续版本使用应用内更新。
- 消息在登录后的可见应用窗口中每分钟同步，应用关闭时不会发出操作系统通知；下次打开时获取仍有效的公告。
- 开发窗口继续使用热更新，本轮没有执行安装器覆盖用户现有安装。原 0.2.2 候选保留。
- 全新 Windows 和实际安装升级验收仍按用户要求暂缓；本版继续标记为测试版。更新包的 Minisign 校验不等于 Windows Authenticode 证书签名。
- 新用户体验额度继续为首次启用钱包赠送 20,000 Credits。充值和现金收费保持关闭，赞助界面继续隐藏。
